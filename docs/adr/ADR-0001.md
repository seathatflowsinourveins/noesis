# ADR-0001: Clean Architecture Layers (`L0..L9`), Upstream-Only Native-First & AST Zero-Self-Invention

- **Status:** Accepted
- **Date:** 2026-11-25
- **Evidence Grade:** E4

## Context and Problem Statement

Quantitative repositories routinely accumulate duplicate engines, custom HTTP pollers, custom agent hooks, unpinned dependencies, and brittle code-golfing to satisfy naive line-count gates. `tier0-sota-clean` requires a clean-room architecture anchored strictly to pinned upstream winners, `SOTA_STARRED_AND_BEYOND_MANIFEST.json`, and native `.pre-commit-config.yaml` / `ast-grep` checks with zero self-invented runtime hooks.

## Decision Drivers

- Single-winner dependency discipline per layer (`L0..L9`) locked in `uv.lock`, `upstream-map.toml`, and `SOTA_STARRED_AND_BEYOND_MANIFEST.json`.
- Mechanical structural enforcement against banned libraries, custom engines, raw HTTP/socket polling, and live endpoints via `ast-grep` and upstream `.pre-commit-config.yaml`.
- Zero custom runtime hooks (`0` custom hook scripts or `"hooks"` blocks across `.claude/`, `.codex/`, `.gemini/`).
- Idiomatic, maintainable Python code where module LOC serves as advisory telemetry rather than a build-breaking gate.

## Considered Options

1. **Hard per-file LOC caps with custom runtime hooks** — encourages code-golfing and fragile shell-hook maintenance.
2. **AST structural gates (`ast-grep`) + native `.pre-commit-config.yaml` + single-winner `uv.lock` + `SOTA_STARRED_AND_BEYOND_MANIFEST.json` + immutable `risk.py` SHA-256 + advisory LOC telemetry**.

## Decision Outcome

Adopt Option 2 across all 10 architecture layers (`L0` Runtime `uv`; `L1` Data `Polars`/`DuckDB`/`Pandera`/`exchange_calendars`/`EdgarTools`/`FRED`; `L2` Signals `ml4t-engineer`/`River`/`Ruptures`/`Stumpy`/`LightGBM`/`CatBoost`/`SHAP`; `L3` Execution `NautilusTrader v2` + `hftbacktest`; `L4` Broker `alpaca-py`; `L5` Falsification `skfolio`/`ml4t-diagnostic`/`arch`/`statsmodels`/`QuantStats`; `L6` Observability `MLflow`/`Dagster`/`Optuna`/`Zensical`/`Prometheus`/`OTel`; `L7` Quality `ruff`/`ty`/`ast-grep`/`gitleaks`/`Hypothesis`/`pytest`/`pre-commit`; `L8` Evals `Inspect AI`/`DSPy`; `L9` Harness `Orca`/`codebase-memory`/`XERJ`/`FastMCP`).

### Consequences

- **Positive:** Zero shadow engines, zero custom runtime hooks, zero banned packages, clean readable modules, deterministic `uv` environment.
- **Negative:** New external packages require explicit vetting in `SOTA_STARRED_AND_BEYOND_MANIFEST.json` and `upstream-map.toml` before locking.
