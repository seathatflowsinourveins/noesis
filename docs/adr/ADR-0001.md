# ADR-0001: Clean Architecture Layers (L0..L10), Upstream-Only Native-First & Zero Self-Hallucination

## Context and Problem Statement

Quantitative repositories routinely accumulate duplicate engines, custom HTTP pollers, ungrouped shelf-ware dependencies, transitive banned packages (`yfinance`, `quantstats`), non-OSI licensed tools, hand-edited drifting manifests, and arbitrary self-invented line-count caps that encourage code-golfing instead of genuine upstream convergence.

## Decision Drivers

- Lock a single OSI-compliant upstream winner per capability across `L0..L10` using PEP 735 `[dependency-groups]` (`dev`, `research`, `evals`, `portals`, `observability`) and `mise.toml` (12 pinned upstream CLIs, zero overlapping tool managers).
- Enforce an SPDX OSI license firewall (`spdx_license_firewall`) excluding non-OSI source-available, proprietary-rule, or non-commercial-weight artifacts (`BSL-1.1`, `ELv2`, custom/unlicensed, non-commercial weights).
- Separate `uv.lock`-installed Python runtime packages from Docker-hosted portals/sandboxes (`aideml`, `otel-collector-contrib`, `grafana`, `caddy`), external host UI plugins (`finos-workspace`, `OpenBB`, `perspective`, `lightweight-charts`, `ag-grid-community`), and vendored skills (`skillevaluator`) so manifest claims match repo ground truth 100%.
- Derive `ARCHITECTURE_MANIFEST.json` and `LLM_HARNESS_MANIFEST.json` programmatically (`scripts/sync_manifest.py`) with zero arbitrary LOC caps.

## Considered Options

1. **Arbitrary LOC caps, ungrouped dependencies, and manual manifests** — itself a form of self-invention that causes code-golfing, `DEP002`/`DEP003` noise, and silent drift.
2. **Full `L0..L10` OSI-vetted upstream stack + `mise`/`just`/`prek`/`fnox`/`age` + PEP 735 `uv.lock` + `ast-grep`/`deptry`/`ruff`/`ty`/`zizmor`/`trivy`/`gitleaks` + programmatic `scripts/sync_manifest.py` (zero arbitrary LOC caps)**.

## Decision Outcome

Adopt Option 2 across all 11 active layers (`L0..L10`) in `upstream-map.toml`, `pyproject.toml`, `mise.toml`, and `scripts/sync_manifest.py`:

- **`L0` Runtime, Lockfile & Secrets (`mise.toml` + `fnox.toml`, [ADR-0023](ADR-0023.md)):** `uv`, `mise`, `just`, `fnox`, `age`.
- **`L1` Data, Schema & PIT ([ADR-0003](ADR-0003.md), [ADR-0013](ADR-0013.md)):** `polars`, `duckdb`, `pandera`, `pydantic` v2, `exchange_calendars` (`XNYS`), `edgartools`, `fredapi`, `treeverse/dvc`.
- **`L2` Features, Drift, Regime & ML ([ADR-0014](ADR-0014.md), [ADR-0015](ADR-0015.md)):** `ml4t-engineer`, `river`, `ruptures`, `stumpy`, `lightgbm`, `catboost`, `shap`.
- **`L3` Single-Engine Parity ([ADR-0016](ADR-0016.md)):** `nautilus_trader` (`LGPL-3.0-only`), Rust `hftbacktest` (`MIT`).
- **`L4` Paper Broker & Market Data ([ADR-0009](ADR-0009.md), [ADR-0010](ADR-0010.md), [ADR-0013](ADR-0013.md)):** `alpaca-py`, `tradermonty/claude-trading-skills`.
- **`L5` Falsification & Portfolio ([ADR-0015](ADR-0015.md), [ADR-0016](ADR-0016.md)):** `skfolio`, `clarabel` (`Clarabel.rs`), `ml4t-diagnostic`, `arch`, `statsmodels`.
- **`L6` Portals, Orchestration, Telemetry & Docs ([ADR-0017](ADR-0017.md), [ADR-0024](ADR-0024.md)):** `mlflow`, `dagster`, `dagster-webserver`, `optuna`, `optuna-dashboard`, `zensical`, `prometheus-client`, `opentelemetry-sdk`, `otel-collector-contrib`, `grafana`, `caddy`.
- **`L7` Quality, AST, SMT & Supply Chain ([ADR-0005](ADR-0005.md), [ADR-0012](ADR-0012.md)):** `ruff`, `ty`, `ast-grep`, `gitleaks`, `hypothesis`, `pytest`, `prek` (single hook runner; duplicate `pre-commit` pruned), `z3-solver`, `deptry`, `trivy`, `syft`, `shellcheck`, `zizmor`, `codeql`, `dependabot`.
- **`L8` Agent Evals, Sandboxes & Prompt Optimization ([ADR-0018](ADR-0018.md)):** `inspect-ai`, `dspy`, `gepa` (in `uv.lock`), `skillevaluator` (vendored skill), `aideml` (isolated Docker sandbox profile `docker/Dockerfile.sandbox`). - **`L9` Multi-Model Harness, Code Graph & MCPs ([ADR-0012](ADR-0012.md), [ADR-0018](ADR-0018.md), [ADR-0022](ADR-0022.md)):** `orca`, `omniroute`, `codebase-memory-mcp`, `xerj`, `mcp`, `edgartools`.

## Consequences

- **Positive:** Locks a single OSI-compliant upstream winner per layer (`L0..L10`) in `uv.lock` and `mise.toml`, eliminates manual manifest drift via `scripts/sync_manifest.py`, keeps `deptry .` scanning all first-party modules including `evals/` and `scripts/run_compounding_reflection.py` with zero `DEP003`, and avoids LOC-golfing distortions.
- **Negative:** Requires updating `upstream-map.toml`, `pyproject.toml`, and re-running `scripts/sync_manifest.py --write` whenever a layer dependency changes.

## Pros and Cons of the Options

### Option 1: Arbitrary LOC caps, ungrouped dependencies, and manual manifests

- Good, because it requires no manifest generator script initially.
- Bad, because LOC caps encourage code-golfing defects, ungrouped dependencies pollute `DEP002`/`DEP003`, and manual JSON inventories inevitably drift from real code.

### Option 2: OSI-vetted `L0..L10` stack + PEP 735 `uv.lock` + programmatic `sync_manifest.py`

- Good, because single-winner discipline, SPDX OSI firewall checks, `ast-grep` rules, and deterministic manifest generation verify architecture mechanically on every commit.
- Bad, because promoting a new upstream requires updating `upstream-map.toml`, `pyproject.toml`, and the corresponding living ADR ([ADR-0024](ADR-0024.md)).

## More Information

### Upstream Evidence & Empirical Benchmarks

- **PEP 735 & `astral-sh/uv` (`uv.lock`):** Official dependency groups (`[dependency-groups]` + `[tool.uv] default-groups`) separate core runtime packages from research, evals, portals, observability, and dev dependencies while enforcing zero `yfinance`/`quantstats` and zero `pre-commit` overlap with `prek`.
- **Tooling & Supply Chain:** `jdx/mise` (`mise.toml`, 12 pinned CLIs including `fnox` and `age`), `casey/just` (`justfile`), `j178/prek` (`.pre-commit-config.yaml`), `ast-grep/ast-grep` (`sgconfig.yml`), `fpgmaas/deptry` (full-tree scan with `0` `DEP003` and `<= 3` optional-LLM `DEP002`), `astral-sh/ruff`, `astral-sh/ty`, `aquasecurity/trivy`, `anchore/syft`, `zizmorcore/zizmor`, `gitleaks/gitleaks`, GitHub native `CodeQL`/`Dependabot`, and SPDX OSI license classification.

### Self-Invention Lesson Learned & Mechanical Upstream Gate

- **Lesson Learned:** Arbitrary LOC caps (`loc_enforcement`, `advisory_production_loc`, `advisory_module_loc`), hand-enumerated 1,200-line AST rule bloat, duplicate `pre-commit` alongside `prek`, excluding `evals/` from `deptry`, and hand-edited `ARCHITECTURE_MANIFEST.json` were self-invented friction that degraded code readability and masked drift. All are permanently purged.
- **Mechanical Upstream Gates:** `ast-grep scan --config sgconfig.yml` (21 concise regex rules), `deptry .` (full repository scan including `evals/` and `scripts/run_compounding_reflection.py`), `ruff check .`, `ty check`, `prek run --all-files`, `scripts/sync_manifest.py --check`, `uv.lock` zero `yfinance`/`quantstats`, `trivy`, `zizmor --offline`, `gitleaks`, `just adr-check`, and `tests/test_architecture_manifest.py`.

### Compounding Layer Integration

- `scripts/sync_manifest.py` emits deterministic `ARCHITECTURE_MANIFEST.json` (including `adr_graph` per [ADR-0024](ADR-0024.md)) and `LLM_HARNESS_MANIFEST.json` consumed by CI (`.github/workflows/ci.yml`), `verify_grand_reset.ps1`, and `XERJ` indexing across all 4 compounding lanes (`sim-backtest`, `paper`, `half-auto-tv`, `live`).

### Living Evolution & Supersession Policy

- SOTA upstream convergence per our Core Trading Philosophy (`PHILOSOPHY_COMPOUNDING_MANIFEST.json`) is the sole source of truth. Any ADR in `docs/adr/` can be amended, superseded (`superseded-by`), or retired without artificial numbering caps per [ADR-0024](ADR-0024.md), preserving immutable `src/tier0_sota/risk.py` safety invariants and live broker port isolation.
