# ADR-0001: Clean Architecture Layers (`L0..L10`), Upstream-Only Native-First & Zero Self-Hallucination

- **Status:** Accepted
- **Date:** 2026-11-26
- **Evidence Grade:** E4

## Context and Problem Statement

Quantitative repositories routinely accumulate duplicate engines, custom HTTP pollers, ungrouped shelf-ware dependencies, transitive banned packages (`yfinance`, `quantstats`), non-OSI licensed tools, hand-edited drifting manifests, and arbitrary self-invented line-count caps that encourage code-golfing instead of genuine upstream convergence.

## Decision Drivers

- Lock a single OSI-compliant upstream winner per capability across `L0..L10` using PEP 735 `[dependency-groups]` (`dev`, `research`, `evals`, `portals`, `observability`).
- Enforce an SPDX OSI license firewall (`spdx_license_firewall`) excluding `BSL-1.1`, `ELv2`, and custom non-OSI licenses.
- Derive `ARCHITECTURE_MANIFEST.json` programmatically (`scripts/sync_manifest.py`) so manifests never drift from real repository state.

## Considered Options

1. **Arbitrary LOC caps, ungrouped dependencies, and manual manifests** — itself a form of self-invention that causes code-golfing, `DEP002`/`DEP003` noise, and silent drift.
2. **Full `L0..L10` OSI-vetted upstream stack + `mise`/`just`/`prek` + PEP 735 `uv.lock` + `ast-grep`/`deptry`/`ruff`/`ty`/`zizmor`/`trivy`/`gitleaks` + programmatic `scripts/sync_manifest.py` (zero arbitrary LOC caps)**.

## Decision Outcome

Adopt Option 2 across all 11 layers (`L0` `uv`/`mise`/`just`, `L1` `Polars`/`DuckDB`/`Pandera`/`Pydantic` v2/`XNYS`/`EdgarTools`/`FRED`/`dvc`, `L2` `ml4t-engineer`/`River`/`Ruptures`/`stumpy`/`LightGBM`/`CatBoost`/`SHAP`, `L3` `NautilusTrader v2`/`hftbacktest`, `L4` `alpaca-py`/`claude-trading-skills`, `L5` `skfolio`/`ml4t-diagnostic`/`arch`/`statsmodels`, `L6` `MLflow`/`Dagster`/`Optuna`/`Zensical`/`Prometheus`/`otel-collector-contrib`/`Grafana`/`Caddy`, `L7` `ruff`/`ty`/`deptry`/`ast-grep`/`prek`/`gitleaks`/`zizmor`/`trivy`/`syft`/`CodeQL`/`Dependabot`/`shellcheck`/`z3-solver`/`Hypothesis`/`pytest`, `L8` `Inspect AI`/`DSPy`/`harbor`/`promptfoo`/`skillevaluator`/`OpenHands`/`aideml`, `L9` `Orca`/`OmniRoute`/`codebase-memory-mcp`/`XERJ`/`FastMCP`/`EdgarTools`, `L10` `finos-workspace`/`OpenBB`/`perspective`/`lightweight-charts`/`ag-grid`).

### Upstream Evidence & Official Directives

- **PEP 735 & `astral-sh/uv` (`uv.lock`):** Official dependency groups (`[dependency-groups]` + `[tool.uv] default-groups`) separate core runtime packages from research/evals/portals/observability/dev shelf-ware.
- **Tooling & Supply Chain:** `jdx/mise` (`mise.toml`), `casey/just` (`justfile`), `j178/prek` (`.pre-commit-config.yaml`), `ast-grep/ast-grep` (`sgconfig.yml`), `fpgmaas/deptry`, `astral-sh/ruff`, `astral-sh/ty`, `aquasecurity/trivy`, `anchore/syft`, `zizmorcore/zizmor`, `gitleaks/gitleaks`, GitHub native `CodeQL`/`Dependabot`, and SPDX OSI license classification.

### Self-Invention Lesson Learned & Mechanical Upstream Gate

- **Lesson Learned:** Arbitrary LOC caps (`loc_enforcement`, `advisory_production_loc`, `advisory_module_loc`), hand-enumerated 1,200-line AST rule bloat, ungrouped `DEP002` ignores, and hand-edited `ARCHITECTURE_MANIFEST.json` were self-invented friction that degraded code readability and caused drift. All are permanently purged.
- **Mechanical Upstream Gates:** `ast-grep scan --config sgconfig.yml` (21 concise regex rules), `deptry .` (`0` issues, `0` `DEP003`, `<= 3` optional-LLM `DEP002`), `ruff check .`, `ty check`, `prek run --all-files`, `scripts/sync_manifest.py --check`, `uv.lock` zero `yfinance`/`quantstats`, `trivy`, `zizmor --offline`, `gitleaks`, and `tests/test_architecture_manifest.py`.

### Compounding Layer Integration

- `scripts/sync_manifest.py` emits deterministic `ARCHITECTURE_MANIFEST.json` consumed by CI (`.github/workflows/ci.yml`), `verify_grand_reset.ps1`, and `XERJ` architecture indexing across all 4 compounding lanes (`sim-backtest`, `paper`, `half-auto-tv`, `live`).

### Living Evolution & Supersession Policy

- SOTA upstream convergence per our Core Trading Philosophy (`PHILOSOPHY_COMPOUNDING_MANIFEST.json`) is the sole source of truth. Any ADR in `docs/adr/` can be amended, superseded (`Superseded by ADR-XXXX`), or retired without artificial numbering caps whenever the verified OSI upstream landscape evolves, preserving only immutable `src/tier0_sota/risk.py` safety invariants and live broker port isolation.
