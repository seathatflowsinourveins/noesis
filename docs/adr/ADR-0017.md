# ADR-0017: Native Workstation Hosting, Disk-Z WSL2 Noesis-SOTA, 15-Portal Upstream Engine Stack & Automated Post-Restart Recovery

- **Status:** Accepted
- **Date:** 2026-11-26
- **Evidence Grade:** E4
- **Sole Source of Truth:** SOTA upstream convergence per Core Trading Philosophy
- **Supersedes:** [ADR-0011](ADR-0011.md) (13-portal framing)

## Context and Problem Statement

The Tier-0 engine must run 24/5 on one stationary workstation and survive any Windows, WSL2, or Antigravity restart without manual repair. [ADR-0011](ADR-0011.md) documented only 13 loopback portals and predates the verified 15-portal stack, the OTel health endpoint (`:13133`), OmniRoute (`:20128`), the 5-asset Dagster reflection job with its weekday schedule, the logon keep-up task, and the one-command `just resume` recovery. Without a single authoritative hosting decision, drift between compose files, systemd units, preflight scripts, and docs would silently degrade the four compounding lanes (`sim-backtest`, `paper`, `half-auto-tv`, `live`).

## Decision Drivers

- Host every engine surface natively on Disk-Z (`Z:\noesis`, `Z:\sota-data`, `Z:\workspaces`, `Z:\WSL`) inside the default WSL2 distro `Noesis-SOTA` with `systemd=true`, so a cold boot reconstitutes the stack declaratively.
- Govern resources at three layers: global WSL2 caps (`.wslconfig` memory, swap on Disk-Z, `autoMemoryReclaim=dropcache`, `vmIdleTimeout=-1`), systemd units for host-bound services, and per-container `cpus` / `mem_limit` in `docker/compose.sota.yml`.
- Keep every portal on loopback (`127.0.0.1`), zero live broker ports (`:4001`, `:7496`, `:8798`, `:8796`), `paper_only=True`, and `live_execution_enabled=False`.
- Serve only official upstream images and CLIs (no inline-Python telemetry or HTTP shims) and admit only OSI-approved licenses; source-available (non-OSI) licenses are excluded.
- Recover automatically at logon and verify mechanically with one command, writing an auditable manifest.

## Considered Options

1. **Docker Desktop on Windows with ad-hoc manual start-up and hand-written dashboards** — no systemd, no declarative reconcile, and violates Zero Self-Invention.
2. **Native WSL2 `Noesis-SOTA` + systemd units + Docker Compose + official Caddy/OTel/Prometheus/Grafana, with a Windows logon keep-up task and `just resume` preflight** — declarative, loopback-only, mechanically verified.
3. **Option 2 plus immediate L14 frontier services (Temporal, Loki/Tempo/Pyroscope, Alertmanager, Langfuse, marimo)** — premature: no measured failure yet demands them; deferred until an earned trigger fires.

## Decision Outcome

Adopt Option 2. Option 3 services remain earned-trigger candidates (see *Living Evolution*).

**Host layout.** Default WSL2 distro `Noesis-SOTA` (`/etc/wsl.conf`: `systemd=true`, `automount` disabled, no Windows PATH injection). Windows `.wslconfig` caps VM memory (`80GB`), places swap/crash dumps/distro on Disk-Z, and uses `networkingMode=mirrored`. Verified on the live host: `free -g` reports ~78 GB total inside `Noesis-SOTA`.

**Four systemd units + one timer** (verified `active` by `wsl_systemd_services: active=4/4`): `tier0-duckdb-ui` (DuckDB SQL UI `:4213`, read-only), `tier0-openbb-backend` (OpenBB/FINOS backend `:6900`), `tier0-ollama-docker-bridge`, `tier0-openbb-docker-bridge`, plus `tier0-wsl-cache-reclaim.timer` (periodic page-cache trim).

**Docker Compose (`docker/compose.sota.yml`, project `docker`)** — 11 default-profile services (verified `running=11/11`) with explicit `cpus` / `mem_limit`: `mlflow` (`:5000`), `optuna-dashboard` (`:8080`), `dagster-webserver` (`:3000`), `dagster-daemon`, `inspect-view` (`:7575`), `zensical` (`:8010`), `telemetry-exporter` (`otel/opentelemetry-collector-contrib:0.123.0`, `:9464` / `:4317` / `:4318` / `:13133`), `prometheus` (`prom/prometheus:v3.2.1`, `:9090`, 30d retention), `grafana` (`grafana/grafana:11.5.2`, `:3001`), `xerj` (`:9200`), and `tearsheets` (`caddy:2.9.1-alpine`, `caddy file-server` on `:8793`, read-only manifests mount). Profile `portals` adds `finos-workspace` (`:1420`, `:8000`); profile `sandbox` adds the network-less, read-only, `cap_drop: ALL` `aideml-sandbox`. Containers run as `1000:1000`.

**15 verified portals** (all `127.0.0.1`; `local_portals_15: healthy=15/15`): XERJ `:9200`, Zensical `:8010`, MLflow `:5000`, Dagster `:3000`, Optuna Dashboard `:8080`, Inspect View `:7575`, Prometheus `:9090`, Grafana `:3001`, OTel metrics `:9464/metrics` (real `otelcol_*` series), Caddy tearsheets `:8793` (`Server: Caddy`), FINOS Workspace `:1420`, FINOS API `:8000/health`, OpenBB backend `:6900`, DuckDB SQL UI `:4213`, OTel health `:13133`. OmniRoute (`:20128/api/health`) is a separately gated local router (`omniroute_local_router`), not a counted portal.

**Dagster (`tier0_sota.definitions`)** — 5 assets (`prewall_pit_audit`, `risk_kernel_sha256_attestation`, `paper_farm_performance_snapshot`, `inspect_safety_and_philosophy_eval`, `compounding_self_reflection_snapshot`), job `compounding_reflection_job`, and `daily_compounding_reflection_schedule` (`0 18 * * 1-5`, `America/New_York`). `docker/dagster.yaml` sets `QueuedRunCoordinator` with `max_concurrent_runs: 1`, `run_monitoring.max_runtime_seconds: 1800`, and `telemetry.enabled: false`.

**Automated post-restart recovery.** The Windows scheduled task `Noesis Orca Mesh Keep-Up` (logon and every 5 minutes, windowless) warms `Noesis-SOTA`, brings up the units and compose stack, ensures OmniRoute (`:20128`) autostart, and refreshes the preflight manifest on fresh boot. `just resume` runs `scripts/preflight_resume.ps1 -Reconcile` (Windows) or `scripts/preflight_resume.sh --reconcile` (WSL2); `just preflight` is the read-only variant.

### Self-Invention Lesson Learned & Mechanical Upstream Gate

- **Lesson Learned:** Hosting facts drifted when stated by prose (13 vs 15 portals; 11 vs 13 gates). The single source is now the machine-written preflight manifest plus the compose file, not narrative counts. Earlier inline-Python metrics and `http.server` shims were already replaced by official OTel Collector and Caddy ([ADR-0011](ADR-0011.md)).
- **Mechanical Upstream Gates:** `just resume` / `just preflight` (13 gates, atomic manifest write), `scripts/grand_reset/verify_grand_reset.ps1`, `tests/test_grand_reset_kit.py` (compose mounts, no live ports, MADR sections), `shellcheck` + `bash -n` on `scripts/preflight_resume.sh`, `rules/zero_self_invention.yml`, `trivy fs`, `gitleaks`, and `zensical build --clean --strict`.
- **Safety:** Recovery tooling never issues host or VM shutdown/restart commands; it only starts, probes, and reconciles.

### Compounding Layer Integration

- `sim-backtest`: MLflow, Optuna, Caddy tearsheets, XERJ. `paper`: DuckDB UI, FINOS, OpenBB, Grafana, OTel for `ALPACA_PA1..PA3` / `IBKR_DU_4002` telemetry ([ADR-0009](ADR-0009.md)). `half-auto-tv`: staged tickets under `tv_sota_pack` ([ADR-0010](ADR-0010.md)). `live`: Z3 proofs, Inspect safety evals, and the preflight `PASS` as the precondition for any Stage-5 dossier.
- Dagster's weekday reflection job consumes `paper_farm_live_performance_manifest.json` and writes into the self-reflection manifest that feeds the next Optuna/MLflow cycle.
- Resume playbook: [`docs/POST_RESTART_RESUME_PLAYBOOK.md`](../POST_RESTART_RESUME_PLAYBOOK.md).

### Living Evolution & Supersession Policy

- This ADR supersedes [ADR-0011](ADR-0011.md) and is itself open to amendment or supersession (`Superseded by ADR-XXXX`) whenever a verified OSI upstream better realizes the Core Trading Philosophy; no artificial count cap applies.
- **L14 earned-trigger candidates (not adopted now):** Temporal (durable multi-hour workflows, MIT) when a Dagster run exceeds the 1800 s monitor or needs human-in-the-loop resume; Prometheus Alertmanager (Apache-2.0) when a pager-grade alert is first required; Grafana Loki / Tempo / Pyroscope (AGPL-3.0) when logs, traces, or profiles are needed beyond OTel metrics; Langfuse (MIT) when LLM trace volume exceeds MLflow tracing; marimo (Apache-2.0) for reactive research notebooks. Each requires a measured trigger, an OSI license check, a compose `cpus`/`mem_limit`, and a preflight gate before adoption.
- Immutable invariants never change by amendment: `risk.py` digest, `paper_only=True`, `live_execution_enabled=False`, zero live broker ports.
