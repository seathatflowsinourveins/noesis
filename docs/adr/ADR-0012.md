# ADR-0012: AAIF AGENTS.md SSOT, 8 Supported Runtimes (incl. OMP/Pi), 4-Runtime Workers, 6/6 MCP Parity, mise/just/prek, OmniRoute & Grand-Reset

## Context and Problem Statement

Operating across eight clean LLM-native agent runtimes (`Antigravity` [`AGY 2.0`], `Claude Code` [`2.1.332`], `Codex` [`0.171.0`], `OpenCode` [`2.3.0`], `oh-my-pi` [`omp v19.2.1`, MIT, `can1357/oh-my-pi`], `pi` [`v1.6.1`, MIT, `earendil-works/pi`], `Gemini CLI`, and `Orca` + `OmniRoute :20128` [`590` routed models]) spanning Windows 11, WSL2 `Noesis-SOTA`, and GitHub Actions causes instruction drift, custom shell-hook breakage, global API-key collisions, external-repo skill coupling, and workstation clutter unless every runtime converges on one AAIF `AGENTS.md` SSOT, exact `6/6` native `uv` stdio MCP parity, `4`-runtime `7/7` typed worker parity, PR-only isolated worktree landing (`protect-main`), declarative `mise`/`just`/`prek`/`fnox`, standalone `.claude/skills/`, `OmniRoute` local routing, and an idempotent Grand-Reset + Post-Restart Resume kit.

## Decision Drivers

- Establish `AGENTS.md` as the single AAIF repository SSOT across all **8 supported runtimes** (`CLAUDE.md` -> `@AGENTS.md`, `.gemini/settings.json` native `context.fileName`, `.codex/config.toml`, `opencode.json`, `.omp/mcp.json` + `.omp/agents/*.md`, `orca.yaml`, and byte-identical Windows + WSL2 Global Workstation Charters incl. `~/.omp/agent/AGENTS.md` & `~/.pi/agent/AGENTS.md`).
- Enforce **`4`-runtime `7/7` typed worker parity** (`.claude/agents/*.md`, `.codex/agents/*.toml`, `opencode.json` `"agent"`, `.omp/agents/*.md`) with mechanical read-only `paper-gatekeeper` enforcement per runtime, **`6/6` exact `(command, args, env)` stdio MCP parity** (`.mcp.json`, `.claude/settings.json`, `.codex/config.toml`, `.gemini/settings.json`, `opencode.json`, `.omp/mcp.json`) + Antigravity `config/mcp_config.json`, zero self-invented runtime hooks (`hooks = false`, preserving only official upstream Orca status hooks under `~/.orca/agent-hooks/` per [ADR-0022](ADR-0022.md)), `22` `ast-grep` rules (including rule #22 `no-handbuilt-plotly-chart`), and the owner's `2026-11-27` **`protect-main` PR-only isolated worktree landing policy** (never edit `Z:\noesis` directly; work in isolated worktrees and land via `gh pr create` + `gh pr merge --auto --squash`).
- Run all local and CI verification through `mise.toml` (**13 pinned upstream CLIs** incl. `node = "24"`, zero `osv-scanner`), `justfile`, `.pre-commit-config.yaml` (`prek` single runner — duplicate `pre-commit` pruned), and 5 SHA-pinned workflows (`.github/workflows/{ci,security,docs,release,multi-model-sota}.yml`, including Trivy SPDX license audit, CrossHair PEP-316 proofs, and Inspect AI `7/7` checks) with zero `GEMINI_API_KEY`.
- Maintain 4 active compounding harness lanes (`.claude/commands/lane-{sim,paper,tv,live}.md`), scoped `.claude/mcp-lanes/`, `46/46` SHA-locked standalone skills in `.claude/skills/` (`UPSTREAM_SKILLS_LOCK.json`, zero-copy discovered in Antigravity per [ADR-0022](ADR-0022.md)), encrypted `fnox`+`age` secret profiles ([ADR-0023](ADR-0023.md)), `15/15` baseline portals (`+ 3` extended = `18` total, plus `marimo :2718`), living executable MADR 4.0 ADRs ([ADR-0024](ADR-0024.md)), and clean Disk-Z active roots (`Z:\noesis`, `Z:\sota-data`, `Z:\workspaces`).

## Considered Options

1. **Duplicated per-runtime instruction charters, third-party hook-heavy wrappers (`omc`/`omx`/`omo`/`oh-my-harness`), direct edits in production `Z:\noesis`, global API-key overrides, fixed ADR caps, and ad-hoc shell wrappers** — drifts across runtimes, hangs sessions on stop-hooks, breaks native OAuth, and destroys standalone portability.
2. **AAIF `AGENTS.md` SSOT across 8 Supported Runtimes (incl. `omp v19.2.1` + `pi v1.6.1`) + `4`-Runtime `7/7` Typed Workers + Exact `6/6` Native `uv` MCP Parity (+ AGY) + `protect-main` Isolated Worktree PR Policy + `mise` (13 CLIs) / `just` / `prek` / `fnox` + `OmniRoute` (`:20128`, `590` models) & WSL2-Safe Orca Failover + Standalone `.claude/skills/` (`46/46`) + Living Executable `ADR-0001+` + Idempotent Grand-Reset & Post-Restart Resume Kits**.

## Decision Outcome

Adopt **Option 2**. All **8 supported runtimes** (`Antigravity` `AGY 2.0`, `Claude Code 2.1.332`, `Codex 0.171.0` with `.codex/config.toml` `[features] multi_agent_v2 = true`, `memories = true`, `goals = true`, `hooks = false`, `OpenCode 2.3.0`, `oh-my-pi` [`omp v19.2.1`, MIT, `can1357/oh-my-pi`], `pi` [`v1.6.1`, MIT, `earendil-works/pi`], `Gemini CLI`, and `Orca` + `OmniRoute :20128`) inherit one concise AAIF `AGENTS.md` SSOT, **`4`-runtime `7/7` typed worker parity** (`.claude/agents/*.md`, `.codex/agents/*.toml`, `opencode.json` `"agent"`, `.omp/agents/*.md`, with mechanical per-runtime read-only `paper-gatekeeper`), and exact normalized `(command, args, env)` 4-server native `uv` stdio MCP parity (`codebase-memory`, `edgartools` -> canonical `L1`, `nautilus-engine`, `xerj`) across **`6/6` repo configs** (`.mcp.json`, `.claude/settings.json`, `.codex/config.toml`, `.gemini/settings.json`, `opencode.json`, `.omp/mcp.json`) plus Antigravity `~/.gemini/config/mcp_config.json`, with zero custom runtime hooks and `22` `ast-grep` rules (`no-handbuilt-plotly-chart`).

### Multi-Runtime Clean Resolution & Hook-Wrapper Disposition

- **Why `omp v19.2.1` + `pi v1.6.1` + Native Typed Workers Win Cleanly:** Native declarative worker specs across Claude Code, Codex, OpenCode, and `oh-my-pi` (`.omp/agents/*.md`, `.omp/mcp.json`) plus minimalist headless/RPC `pi v1.6.1` run directly over `OmniRoute :20128` (`590` routed models) with zero stop-hook deadlocks, mechanical per-runtime read-only `paper-gatekeeper` enforcement verified by `scripts/sync_manifest.py`, and zero-copy/synced skills parity.
- **Permanently Purged Hook-Heavy Wrappers (`hooks = false`):** Third-party hook-heavy plugins and overlays — `Yeachan-Heo/oh-my-claudecode` (`omc`), `oh-my-codex` (`omx`), `oh-my-opencode` (`omo`), `oh-my-harness`, `codex@openai-codex` `900s` stop-hooks, `~/.codex/plugins/cache/oh-my-codex-local`, and disabled `superpowers` — remain permanently purged under the clean host-reset policy (`hooks = false`, zero `.omp/hooks*`).
- **PR-Only Isolated Worktree Landing Policy (`protect-main`, owner decision `2026-11-27`):** `main` accepts changes strictly through pull requests with green required checks (no direct push, no bypass). Every agent and automation edits exclusively inside an isolated git worktree/clone (never in the production tree `Z:\noesis` imported by live services) and lands via `gh pr create` + `gh pr merge --auto --squash`.
- **Native OAuth Commands Ready for Owner Login (Zero Global API-Key Overrides):** Interactive sessions authenticate natively via `omp login openai-codex`, `omp login anthropic`, `omp --from-codex`, and `pi auth login`, alongside native Claude Code / Codex / Orca OAuth logins.

- **Declarative Cross-OS Toolchain:** `mise.toml` pins **13 upstream CLIs** (`python 3.13`, `node 24`, `uv 0.13`, `just 1.59`, `ruff 0.17`, `gitleaks 8.30`, `trivy 0.76`, `zizmor 1.32`, `syft 1.55`, `prek 0.5`, `ast-grep 0.51`, `fnox 1.50`, `age 1.3`) with **zero `osv-scanner`** (replaced by `Trivy` + `Syft` + `Dependabot`) and **zero duplicate `pre-commit`** (replaced by `prek`). `justfile` runs identical cross-platform tasks on Windows (`pwsh`) and WSL2 (`bash`), and `prek` enforces `.pre-commit-config.yaml` locally (`core.hooksPath=.git/hooks`).
- **Three-Tier Auth, `OmniRoute`, `fnox` & WSL2-Safe Orca Failover:** Detailed three-tier auth and Orca failover live in [ADR-0018](ADR-0018.md) and encrypted paper/data secret profiles live in [ADR-0023](ADR-0023.md). Interactive `Claude Code`, `Codex`, `omp`, and `pi` sessions use native OAuth logins only (`zero_global_api_key_override = true`), local headless automations route through `OmniRoute` (`http://127.0.0.1:20128/api/health`, `590` routed models), banked `anthropic` and `openai` keys are reserved for explicit high-quality CI dispatches in `.github/workflows/multi-model-sota.yml`, and WSL2-safe `scripts/orca_account_failover.py` (`just account-status` / `just account-switch`) resolves `ORCA_CLI_COMMAND` / `orca-ide` on POSIX (explicitly refusing GNOME `/usr/bin/orca` + symlinks) and `orca` only on Windows while redacting secrets from error text.
- **Workstation Topology, Zero-Copy Skills, `15/15` (`18` Total) Portals & Living `ADR-0001+`:** Active Disk-Z roots stay strictly partitioned into `Z:\noesis`, `Z:\sota-data` (`prewall-lake`, `manifests`), and `Z:\workspaces` (`ORCA_WORKSPACES_DIR`). ## Consequences

- **Positive:** Unifies all **8 agent runtimes** (incl. `oh-my-pi` `v19.2.1` and `pi` `v1.6.1`) under one `AGENTS.md` SSOT, `4`-runtime `7/7` typed worker parity with mechanical read-only `paper-gatekeeper`, exact `(command, args, env)` **`6/6` native `uv` stdio MCP parity**, `protect-main` PR-only worktree isolation, 13 declarative `mise.toml` CLIs (`node 24`, `prek` single runner, `fnox`+`age`), `22` `ast-grep` rules (`no-handbuilt-plotly-chart`), `46/46` SHA-locked standalone skills with zero-copy AGY discovery, `OmniRoute :20128` (`590` routed models), WSL2-safe Orca failover, and idempotent Grand-Reset/Resume kits.

## Pros and Cons of the Options

### Option 1: Per-runtime instruction copies, hook-heavy wrappers (`omc`/`omx`/`omo`/`oh-my-harness`), and ad-hoc shell wrappers

- Good, because each runtime can be tweaked independently in the short term.
- Bad, because instructions and MCP configs diverge rapidly, third-party stop-hooks hang sessions (`900s`), and global API-key exports lock out native OAuth subscriptions.

### Option 2: Unified AAIF `AGENTS.md` SSOT across 8 Runtimes + `4`-Runtime Workers + `6/6` MCP Parity + 13-CLI `mise.toml` + `prek`/`fnox` + Grand-Reset kit

- Good, because all 8 runtimes across Windows, WSL2, and CI share one audited source of truth with mechanical parity verification and clean PR-only worktree isolation.
- Bad, because adding a new MCP server, typed worker role, or CLI tool requires updating the synchronized parity configs and `mise.toml`.
