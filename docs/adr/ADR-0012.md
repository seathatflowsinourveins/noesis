# ADR-0012: Multi-Runtime LLM-Native Harness, Standalone `.claude/skills/` & Clean Disk-Z + WSL2 Grand-Reset Architecture

- **Status:** Accepted
- **Date:** 2026-11-25
- **Evidence Grade:** E4

## Context and Problem Statement

Operating across Claude Code, Codex, Antigravity (AGY), OpenCode, and Orca risks configuration drift, fragile custom shell hooks, external-repo skill coupling, and stale legacy directories unless runtimes use pure native upstream `uv` MCPs, standalone `.claude/skills/`, few-line per-lane harnesses, and an idempotent Disk-Z + WSL2 + fresh AGY Grand-Reset kit.

## Decision Drivers

- **Zero self-invented runtime hooks:** Zero `"hooks"` keys in `.claude/settings.json` and `.gemini/settings.json`, zero `.codex/hooks.json`, and zero `bash -c` wrappers (pure native `uv run --no-sync` MCPs).
- **100% Standalone Vetted Skills (`46`):** All `46` vetted skills locked in `UPSTREAM_SKILLS_LOCK.json` live directly inside `.claude/skills/` with zero dependency on external repositories.
- **Few-line per-lane harnesses & scoped MCPs:** Concise `.claude/agents/*.md` (`<= 16` lines), `.claude/commands/*.md` (`<= 10` lines), read-only `paper-gatekeeper` (`permissionMode: plan`), and scoped `.claude/mcp-lanes/*.mcp.json` (`sim`, `paper`, `tv`, `gate`).
- **Strict 4-MCP parity & parameterized Grand-Reset:** `codebase-memory`, `xerj`, `nautilus-engine` FastMCP, `edgartools` across `.mcp.json`, `.claude/`, `.codex/`, `.gemini/`, `opencode.json`, plus `SOTA_STARRED_AND_BEYOND_MANIFEST.json` (`zero_self_invented_hooks = true`, `spdx_license_firewall`) and parameterized `$TIER0_REPO_ROOT` / `$TIER0_DATA_ROOT` / `$TIER0_WSL_DISTRO`.

## Considered Options

1. **Manual workstation configs with custom agent hook scripts and external-repo skill paths** — brittle across Windows/WSL2 and breaks standalone portability.
2. **Zero-Hook Native `uv` MCPs + Standalone `.claude/skills/` (`46`) + Few-Line Scoped Harnesses + Idempotent Disk-Z / Fresh-AGY Grand-Reset Kit (`scripts/grand_reset/00..03` + `verify_grand_reset.ps1`)**.

## Decision Outcome

Adopt Option 2. All 4 agent runtimes use clean native `uv` MCP invocations with zero self-invented hooks; static/security checks stay in `.pre-commit-config.yaml` and `pytest`. All `46` vetted skills copy strictly from `$RepoRoot\.claude\skills` during setup. End-to-end Disk-Z, fresh AGY reinstall, WSL2, Docker, and Paper Farm provisioning runs non-destructively via `scripts/grand_reset/00_clean_disk_z_and_agy_reset.ps1` -> `01_disk_z_and_wsl_setup.ps1` -> `02_runtimes_agy_orca_setup.ps1` -> `03_hosted_stack_tv_paper.ps1` -> `verify_grand_reset.ps1` (`12/12` gates).

### Consequences

- **Positive:** 100% standalone, zero-hook multi-runtime parity and one-command clean Disk-Z + fresh Antigravity recovery.
- **Negative:** Requires keeping `ARCHITECTURE_MANIFEST.json`, `SOTA_STARRED_AND_BEYOND_MANIFEST.json`, `.claude/skills/`, and `UPSTREAM_SKILLS_LOCK.json` synchronized when adding vetted skills or scripts.
