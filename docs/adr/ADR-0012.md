# ADR-0012: AAIF `AGENTS.md` SSOT, 6 Supported Runtimes, `mise`/`just`/`prek`, Standalone Skills, `OmniRoute` & Grand-Reset

- **Status:** Accepted
- **Date:** 2026-11-26
- **Evidence Grade:** E4
- **Sole Source of Truth:** SOTA upstream convergence per Core Trading Philosophy

## Context and Problem Statement

Operating across six supported agent runtimes (`Codex`, `Claude Code`, `Gemini CLI`, `OpenCode`, `Antigravity`, and `Orca`) spanning Windows 11, WSL2 `Noesis-SOTA`, and GitHub Actions causes instruction drift, custom shell-hook breakage, global API-key collisions, external-repo skill coupling, and workstation clutter unless every runtime converges on one AAIF `AGENTS.md` SSOT, native `uv` stdio MCPs, declarative `mise`/`just`/`prek`, standalone `.claude/skills/`, `OmniRoute` local routing, and an idempotent Grand-Reset + Post-Restart Resume kit.

## Decision Drivers

- Establish `AGENTS.md` as the single AAIF repository SSOT across all 6 supported runtimes (`CLAUDE.md` -> `@AGENTS.md`, `.gemini/settings.json` native `context.fileName`, `opencode.json`, `orca.yaml`, and `8/8` byte-identical Windows + WSL2 Global Workstation Charter SHA-256 `057933bbda0db411bbfbc189c72a3e7b59f1989650e110f8591cf64728555c1c`).
- Enforce zero self-invented runtime hooks (`hooks_zero = True`, preserving only official upstream Orca status hooks under `~/.orca/agent-hooks/`) and zero arbitrary LOC caps; run all local and CI verification through `mise.toml` (10 pinned upstream CLIs, zero `osv-scanner`), `justfile`, `.pre-commit-config.yaml` (`prek`), and 5 SHA-pinned workflows (`.github/workflows/{ci,security,docs,release,multi-model-sota}.yml`) with zero `GEMINI_API_KEY`.
- Maintain 4 active compounding harness lanes (`.claude/commands/lane-{sim,paper,tv,live}.md`), scoped `.claude/mcp-lanes/`, `46/46` SHA-locked standalone skills in `.claude/skills/` (`UPSTREAM_SKILLS_LOCK.json`), `15/15` hosted portals plus `OmniRoute` (`:20128`), living open-ended MADR 4.0 ADRs (`ADR-0001+`), and clean Disk-Z active roots (`Z:\noesis`, `Z:\sota-data`, `Z:\workspaces`).

## Considered Options

1. **Duplicated per-runtime instruction charters, custom runtime hooks, global API-key overrides, fixed ADR caps, and ad-hoc shell wrappers** — drifts across runtimes, breaks native OAuth sessions, and destroys standalone portability.
2. **AAIF `AGENTS.md` SSOT across 6 Supported Runtimes + Native `uv` MCP Parity (`5/5` repo + AGY) + `mise` (10 CLIs) / `just` / `prek` + `OmniRoute` (`:20128`) & Orca Failover + Standalone `.claude/skills/` (`46/46`) + `15/15` Portals + Living Open-Ended `ADR-0001+` + Idempotent Grand-Reset & Post-Restart Resume Kits**.

## Decision Outcome

Adopt **Option 2**. All 6 supported runtimes (`Codex`, `Claude Code`, `Gemini CLI`, `OpenCode`, `Antigravity`, `Orca`) inherit one concise AAIF `AGENTS.md` SSOT and exact 4-server native `uv` stdio MCP parity (`codebase-memory`, `edgartools`, `nautilus-engine`, `xerj`) across `5/5` repo configs (`.mcp.json`, `.claude/settings.json`, `.codex/config.toml`, `.gemini/settings.json`, `opencode.json`) plus Antigravity `~/.gemini/config/mcp_config.json`, with zero custom runtime hooks.

- **Declarative Cross-OS Toolchain:** `mise.toml` pins exactly **10 upstream CLIs** (`python 3.13`, `uv 0.13`, `just 1.59`, `ruff 0.17`, `gitleaks 8.30`, `trivy 0.76`, `zizmor 1.32`, `syft 1.55`, `prek 0.5`, `ast-grep 0.51`) with **zero `osv-scanner`** (replaced by `Trivy` + `Syft` + `Dependabot`). `justfile` runs identical cross-platform tasks on Windows (`pwsh`) and WSL2 (`bash`), and `prek` enforces `.pre-commit-config.yaml` locally (`core.hooksPath=.git/hooks`).
- **Three-Tier Auth, `OmniRoute` & Zero `GEMINI_API_KEY`:** Interactive `Claude Code` and `Codex` sessions use native Orca OAuth logins only (`zero_global_api_key_override = true`, unrestricted model catalog, zero `GEMINI_API_KEY` anywhere in local env or CI), local headless automations and routine CI route through `OmniRoute` (`http://127.0.0.1:20128/api/health`, native `OmniRoute.vbs` `--no-open --no-tray` autostart), banked `anthropic` and `openai` API keys are restricted exclusively to high-quality SOTA dispatches in `.github/workflows/multi-model-sota.yml`, and `scripts/orca_account_failover.py` (`just account-status` / `just account-switch`) handles rate-limit failover via official Orca CLI commands.
- **Workstation Topology, `15/15` Portals & Living `ADR-0001+`:** Active Disk-Z roots stay strictly partitioned into `Z:\noesis`, `Z:\sota-data` (`prewall-lake`, `manifests`), and `Z:\workspaces` (`ORCA_WORKSPACES_DIR`). `scripts/sync_manifest.py` keeps `ARCHITECTURE_MANIFEST.json` drift-free, `docs/adr/ADR-*.md` stays open-ended (`ADR-0001+`, `adrs_artificial_count_cap = false`) hosted on `Zensical` (`:8010`), `scripts/grand_reset/00..03` + `verify_grand_reset.ps1` (`12/12` gates) provide standalone reproducibility, and `scripts/preflight_resume.{ps1,sh}` (`just preflight` / `just resume`) verify all `13/13` workstation gates (`15/15` portals, `OmniRoute :20128`, Orca multi-account readiness, `0` live broker ports).

### Self-Invention Lesson Learned & Mechanical Upstream Gate

- **Lesson Learned:** Custom runtime hook shims (`rtk`, `harness_directive_hook.py`, `.codex/hooks.json`), redundant `osv-scanner` overlapping `Trivy`, unused `GEMINI_API_KEY` secrets, fixed ADR count caps, defensive boilerplate charter blocks, and arbitrary agent/command line caps caused friction without improving execution safety.
