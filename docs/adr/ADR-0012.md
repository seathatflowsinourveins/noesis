# ADR-0012: AAIF `AGENTS.md` SSOT, 4 Compounding Lanes, `mise`/`just`/`prek`, Standalone Skills & Grand-Reset

- **Status:** Accepted
- **Date:** 2026-11-26
- **Evidence Grade:** E4

## Context and Problem Statement

Operating across Claude Code, Codex, Antigravity (AGY), OpenCode, and Orca across Windows and WSL2 causes instruction drift, custom shell-hook breakage, external-repo skill coupling, and host clutter unless every runtime converges on one AAIF `AGENTS.md` SSOT, native `uv` MCPs, declarative `mise`/`just`/`prek`, standalone `.claude/skills/`, and an idempotent Grand-Reset kit.

## Decision Drivers

- Establish `AGENTS.md` as the single AAIF repo SSOT (`CLAUDE.md` -> `@AGENTS.md`, `.gemini/settings.json` native `context.fileName`, byte-identical 3-bullet Global Workstation Charter across Windows & WSL2).
- Enforce zero self-invented runtime hooks (`hooks_zero = True`) and zero arbitrary LOC caps; run all local/CI verification through `mise.toml`, `justfile`, `.pre-commit-config.yaml` (`prek`), and SHA-pinned `.github/workflows/{ci,security,docs,release}.yml`.
- Maintain 4 active compounding harness lanes (`.claude/commands/lane-{sim,paper,tv,live}.md`), scoped `.claude/mcp-lanes/`, `46` SHA-locked standalone skills in `.claude/skills/`, and clean active roots (`Z:\tier0-sota-clean`, `Z:\sota-data`, `Z:\workspaces`, `Z:\archive`).

## Considered Options

1. **Duplicated per-runtime instruction charters, custom runtime hooks, and ad-hoc shell wrappers** — drifts across runtimes and breaks standalone portability.
2. **AAIF `AGENTS.md` SSOT + `@AGENTS.md` pointers + 4 Active Compounding Lanes + Native `uv` MCPs + `mise`/`just`/`prek` + Standalone `.claude/skills/` (`46`) + Idempotent Grand-Reset Kit**.

## Decision Outcome

Adopt Option 2. All 4 agent runtimes inherit one concise AAIF `AGENTS.md` SSOT and exact 4-server native `uv` MCP parity (`codebase-memory`, `xerj`, `nautilus-engine`, `edgartools`) with zero custom runtime hooks. `mise.toml` pins 11 upstream CLIs, `justfile` runs identical cross-platform tasks on Windows (`pwsh`) and WSL2 (`bash`), `prek` enforces `.pre-commit-config.yaml` locally (`core.hooksPath=.git/hooks`), `scripts/sync_manifest.py` keeps `ARCHITECTURE_MANIFEST.json` drift-free, and `scripts/grand_reset/00..03` + `verify_grand_reset.ps1` (`12/12` gates) ensure clean workstation reproducibility.

### Upstream Evidence & Official Directives

- **Standards & Upstream Harnesses:** AAIF `AGENTS.md` specification, Claude Code `@AGENTS.md` include & `permissionMode: plan`, Gemini CLI `context.fileName`, `stablyai/orca` (`ORCA_WORKSPACES_DIR=Z:\workspaces`), `jdx/mise`, `casey/just`, `j178/prek`, GitHub Actions SHA-pinning (`zizmorcore/zizmor` `--offline` `0` findings), and `modelcontextprotocol/python-sdk`.

### Self-Invention Lesson Learned & Mechanical Upstream Gate

- **Lesson Learned:** Custom runtime hook shims (`rtk`, `harness_directive_hook.py`, `.codex/hooks.json`), defensive boilerplate charter blocks, and arbitrary agent/command line caps caused friction without improving execution safety. All custom hooks and arbitrary caps were permanently purged in favor of upstream `prek`, `ast-grep`, `zizmor`, `trivy`, `gitleaks`, and native `permissions.deny`.
- **Mechanical Upstream Gates:** `prek run --all-files`, `just check`, `zizmor --offline .github/workflows`, `trivy fs --severity HIGH,CRITICAL --exit-code 1 .`, `tests/test_architecture_manifest.py`, `tests/test_grand_reset_kit.py`, and `scripts/grand_reset/verify_grand_reset.ps1` (`12/12`).

### Compounding Layer Integration

- Binds every runtime and operator command directly into the 4 active compounding harness lanes (`sim-backtest`, `paper`, `half-auto-tv`, `live`) and `scripts/sync_manifest.py`, guaranteeing that verified improvements across code, manifests, skills, and ADRs compound cleanly across Windows and WSL2.
