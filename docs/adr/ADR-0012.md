# ADR-0012: AAIF AGENTS.md SSOT, 6 Supported Runtimes, mise/just/prek, Standalone Skills, OmniRoute & Grand-Reset

## Context and Problem Statement

Operating across six supported agent runtimes (`Codex`, `Claude Code`, `Gemini CLI`, `OpenCode`, `Antigravity`, and `Orca`) spanning Windows 11, WSL2 `Noesis-SOTA`, and GitHub Actions causes instruction drift, custom shell-hook breakage, global API-key collisions, external-repo skill coupling, and workstation clutter unless every runtime converges on one AAIF `AGENTS.md` SSOT, native `uv` stdio MCPs, declarative `mise`/`just`/`prek`/`fnox`, standalone `.claude/skills/`, `OmniRoute` local routing, and an idempotent Grand-Reset + Post-Restart Resume kit.

## Decision Drivers

- Establish `AGENTS.md` as the single AAIF repository SSOT across all 6 supported runtimes (`CLAUDE.md` -> `@AGENTS.md`, `.gemini/settings.json` native `context.fileName`, `opencode.json`, `orca.yaml`, and `8/8` byte-identical Windows + WSL2 Global Workstation Charter SHA-256 `9fa037355c3942201e3c0813acaa7b01c590e6294cd5e85787ae1bdcef55a7b8`).
- Enforce zero self-invented runtime hooks (`hooks_zero = True`, preserving only official upstream Orca status hooks under `~/.orca/agent-hooks/` per [ADR-0022](ADR-0022.md)) and zero arbitrary LOC caps; run all local and CI verification through `mise.toml` (**13 pinned upstream CLIs** incl. `node = "24"`, zero `osv-scanner`), `justfile`, `.pre-commit-config.yaml` (`prek` single runner — duplicate `pre-commit` pruned), and 5 SHA-pinned workflows (`.github/workflows/{ci,security,docs,release,multi-model-sota}.yml`) with zero `GEMINI_API_KEY`.
- Maintain 4 active compounding harness lanes (`.claude/commands/lane-{sim,paper,tv,live}.md`), scoped `.claude/mcp-lanes/`, `46/46` SHA-locked standalone skills in `.claude/skills/` (`UPSTREAM_SKILLS_LOCK.json`, zero-copy discovered in Antigravity per [ADR-0022](ADR-0022.md)), encrypted `fnox`+`age` secret profiles ([ADR-0023](ADR-0023.md)), `15/15` baseline portals (`+ 3` extended = `18` total), living executable MADR 4.0 ADRs ([ADR-0024](ADR-0024.md)), and clean Disk-Z active roots (`Z:\noesis`, `Z:\sota-data`, `Z:\workspaces`).

## Considered Options

1. **Duplicated per-runtime instruction charters, custom runtime hooks, global API-key overrides, fixed ADR caps, and ad-hoc shell wrappers** — drifts across runtimes, breaks native OAuth sessions, and destroys standalone portability.
2. **AAIF `AGENTS.md` SSOT across 6 Supported Runtimes + Exact Native `uv` MCP Parity (`5/5` repo + AGY) + `mise` (13 CLIs) / `just` / `prek` / `fnox` + `OmniRoute` (`:20128`) & WSL2-Safe Orca Failover + Standalone `.claude/skills/` (`46/46`) + `15/15` Baseline (`18` Total) Portals + Living Executable `ADR-0001+` + Idempotent Grand-Reset & Post-Restart Resume Kits**.

## Decision Outcome

Adopt **Option 2**. All 6 supported runtimes (`Codex` with `.codex/config.toml` `[features] multi_agent_v2 = true`, `memories = true`, `goals = true`, `Claude Code`, `Gemini CLI`, `OpenCode`, `Antigravity`, `Orca`) inherit one concise AAIF `AGENTS.md` SSOT and exact normalized `(command, args, env)` 4-server native `uv` stdio MCP parity (`codebase-memory`, `edgartools` -> canonical `L1`, `nautilus-engine`, `xerj`) across `5/5` repo configs (`.mcp.json`, `.claude/settings.json`, `.codex/config.toml`, `.gemini/settings.json`, `opencode.json`) plus Antigravity `~/.gemini/config/mcp_config.json`, with zero custom runtime hooks.

- **Declarative Cross-OS Toolchain:** `mise.toml` pins **13 upstream CLIs** (`python 3.13`, `node 24`, `uv 0.13`, `just 1.59`, `ruff 0.17`, `gitleaks 8.30`, `trivy 0.76`, `zizmor 1.32`, `syft 1.55`, `prek 0.5`, `ast-grep 0.51`, `fnox 1.50`, `age 1.3`) with **zero `osv-scanner`** (replaced by `Trivy` + `Syft` + `Dependabot`) and **zero duplicate `pre-commit`** (replaced by `prek`). `justfile` runs identical cross-platform tasks on Windows (`pwsh`) and WSL2 (`bash`), and `prek` enforces `.pre-commit-config.yaml` locally (`core.hooksPath=.git/hooks`).
- **Three-Tier Auth, `OmniRoute`, `fnox` & WSL2-Safe Orca Failover:** Detailed three-tier auth and Orca failover live in [ADR-0018](ADR-0018.md) and encrypted paper/data secret profiles live in [ADR-0023](ADR-0023.md). Interactive `Claude Code` and `Codex` sessions use native Orca OAuth logins only (`zero_global_api_key_override = true`), local headless automations route through `OmniRoute` (`http://127.0.0.1:20128/api/health`), banked `anthropic` and `openai` keys are reserved for explicit high-quality CI dispatches in `.github/workflows/multi-model-sota.yml`, and WSL2-safe `scripts/orca_account_failover.py` (`just account-status` / `just account-switch`) resolves `ORCA_CLI_COMMAND` / `orca-ide` on POSIX (explicitly refusing GNOME `/usr/bin/orca` + symlinks) and `orca` only on Windows while redacting secrets from error text.
- **Workstation Topology, Zero-Copy Skills, `15/15` (`18` Total) Portals & Living `ADR-0001+`:** Active Disk-Z roots stay strictly partitioned into `Z:\noesis`, `Z:\sota-data` (`prewall-lake`, `manifests`), and `Z:\workspaces` (`ORCA_WORKSPACES_DIR`). Antigravity discovers the `46/46` SHA-locked skills zero-copy via `.agents/skills.json` and `~/.gemini/config/skills.json` ([ADR-0022](ADR-0022.md)) rather than copying skill trees onto Disk-C. `scripts/sync_manifest.py` keeps `ARCHITECTURE_MANIFEST.json`, `LLM_HARNESS_MANIFEST.json`, and the ADR graph drift-free ([ADR-0024](ADR-0024.md)); Caddy (`2.11.9-alpine`) hosts tearsheets + Allure 3 (`/test-reports/allure/`) on `:8793` and the `:4213 -> :4214` DuckDB CSRF proxy, alongside profile-gated `Alertmanager :9093`; `scripts/grand_reset/00..03` + `verify_grand_reset.ps1` (`12/12` gates) provide standalone reproducibility, and `scripts/preflight_resume.{ps1,sh}` (`just preflight` / `just resume`) verify all `13/13` always-on workstation gates ([ADR-0017](ADR-0017.md)).

## Consequences

- **Positive:** Unifies 6 agent runtimes under one `AGENTS.md` SSOT, exact `(command, args, env)` `5/5` native `uv` stdio MCP parity, 13 declarative `mise.toml` CLIs (`node 24`, `prek` single runner, `fnox`+`age`), `46/46` SHA-locked standalone skills with zero-copy AGY discovery, `OmniRoute :20128` routing, WSL2-safe Orca failover, and idempotent Grand-Reset/Resume kits.
- **Negative:** Requires keeping `CLAUDE.md`, `.gemini/`, `.codex/`, `opencode.json`, and `orca.yaml` synchronized via `scripts/sync_manifest.py` and `tests/test_grand_reset_kit.py`.

## Pros and Cons of the Options

### Option 1: Per-runtime instruction copies, custom hooks, and ad-hoc shell wrappers

- Good, because each runtime can be tweaked independently in the short term.
- Bad, because instructions and MCP configs diverge rapidly, custom hooks break upgrades, and global API-key exports lock out native OAuth subscriptions.

### Option 2: Unified AAIF `AGENTS.md` SSOT + 12-CLI `mise.toml` + `prek`/`fnox` + Grand-Reset kit

- Good, because all 6 runtimes across Windows, WSL2, and CI share one audited source of truth with mechanical parity verification.
- Bad, because adding a new MCP server or CLI tool requires updating the synchronized parity configs and `mise.toml`.

### Self-Invention Lesson Learned & Mechanical Upstream Gate

- **Lesson Learned:** Custom runtime hook shims (`rtk`, `harness_directive_hook.py`, legacy `.codex` hooks), redundant `osv-scanner` overlapping `Trivy`, duplicate `pre-commit` overlapping `prek`, Disk-C skill copies for AGY, unused `GEMINI_API_KEY` secrets, and fixed ADR count caps caused friction without improving safety. All were permanently purged.
- **Mechanical Upstream Gates:** `prek run --all-files`, `just check`, `just adr-check`, `just docs-build` (`zensical build --clean --strict`), `just preflight` / `just resume`, `zizmor --offline .github/workflows`, `trivy fs`, `evals/tier0_inspect_eval.py`, `tests/test_architecture_manifest.py`, `tests/test_grand_reset_kit.py`, and `scripts/grand_reset/verify_grand_reset.ps1` (`12/12`).
