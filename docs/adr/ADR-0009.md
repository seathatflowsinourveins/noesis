# ADR-0009: Stationary 4-Account Paper Farm Compounding Lane (`ALPACA_PA1..PA3` + `IBKR_DU_4002`)

- **Status:** Accepted
- **Date:** 2026-11-26
- **Evidence Grade:** E4
- **Sole Source of Truth:** SOTA upstream convergence per Core Trading Philosophy

## Context and Problem Statement

Validating multiple intraday archetypes (`ORB Burst`, `Structural Trend`, `AVWAP Tight Lock`) in live markets requires non-overlapping symbol ownership, isolated per-account fill/markout ledgers, continuous compounding manifests, and mechanical isolation from live real-capital broker endpoints.

## Decision Drivers

- Collect continuous ungated live-market merit evidence in the `paper` compounding lane on the stationary Noesis host (`MAC_BROKER_PORTS = 0`).
- Prevent symbol collisions across `ALPACA_PA1` (`L1_ORB_BURST`), `ALPACA_PA2` (`L2_STRUCTURAL_TREND`), and `ALPACA_PA3` (`L3_AVWAP_TIGHT_LOCK`), alongside `IBKR_DU_4002` (`3,000 rpm`, 24/5 overnight).
- Aggregate performance into declarative JSON manifests for `FINOS`, `OpenBB`, `Grafana`, and `OTel` without custom web servers.

## Considered Options

1. **Single shared paper account with mixed strategies** — corrupts per-archetype attribution and creates cross-strategy order races.
2. **Isolated 4-account Paper Farm (`paper_only=True`, `live_execution_enabled=False`) with `CrossLaneSymbolLock`, isolated `DuckDB` ledgers, and declarative `FINOS`/`OpenBB` manifests**.

## Decision Outcome

Adopt Option 2 in `src/tier0_sota/live/paper_farm.py` and `src/tier0_sota/live/performance.py`. Each lane tracks independent status JSON and `DuckDB` telemetry (`paper_lane_{pa1,pa2,pa3}.duckdb`), acquires symbols exclusively via `CrossLaneSymbolLock`, respects `ProtectiveExitRateBudget` (`200 rpm` Alpaca / `3,000 rpm` IBKR), and aggregates equity, drawdown, fills, auto-shorts, reverses, re-entries, and fast-sells into `Z:\sota-data\manifests\paper_farm_live_performance_manifest.json` and `finos_paper_farm_performance.json`.

## Consequences

- **Positive:** Isolates per-archetype fills, `DuckDB` ledgers, and `CrossLaneSymbolLock` ownership across `ALPACA_PA1..PA3` + `IBKR_DU_4002` with zero cross-lane symbol collisions or live port exposure.
- **Negative:** Requires reconciling 4 separate paper account ledgers and enforcing `CrossLaneSymbolLock` exclusivity when multiple strategies signal the same extreme mover.
