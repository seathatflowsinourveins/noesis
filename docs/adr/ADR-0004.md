# ADR-0004: Single-Engine Trading Parity (`NautilusTrader v2` + Rust `hftbacktest`)

- **Status:** Accepted
- **Date:** 2026-11-26
- **Evidence Grade:** E4

## Context and Problem Statement

Maintaining separate Python simulation loops and live broker execution scripts causes structural divergence in fill timing, stop triggers, order throttling, and position state transitions across backtest, paper, and live environments.

## Decision Drivers

- Run identical strategy code across `BacktestEngine`, `Environment.SANDBOX`, and `LiveNode` (`Sim == Paper == Live`).
- Model realistic L1/L2 queue-position fills and adverse-selection markout using Rust `hftbacktest`.
- Rely strictly on native `NautilusTrader v2` `RiskEngineConfig` / `LiveRiskEngineConfig` rate limits (`bypass=False`) without custom shadow order managers.

## Considered Options

1. **Custom Python backtest engine paired with separate REST-polling broker scripts** — breaks `Sim == Paper == Live` parity and violates Zero Self-Invention.
2. **Unified `NautilusTrader v2` (`SignalExecutionStrategy`) + Rust `hftbacktest` queue simulation**.

## Decision Outcome

Adopt Option 2 in `src/tier0_sota/engine.py` and `src/tier0_sota/research.py`. All strategy execution, venue pacing (`IBKR_PAPER_4002` `3,000 rpm`, `ALPACA_PAPER_200` `200 rpm`), and `Environment.SANDBOX` parity checks live directly inside `NautilusTrader v2` primitives paired with Rust `hftbacktest` (`RiskAdverseQueueModel`) L1 markout evaluation.

### Upstream Evidence & Official Directives

- **Execution & Queue Simulation:** `nautechsystems/nautilus_trader` (`2.0.0rc9`: `BacktestEngine`, `LiveNode`, `Environment.SANDBOX`, `RiskEngineConfig`, `OrderEmulator`, `SignalExecutionStrategy`) and `nkaz001/hftbacktest` (`>=2.4.0`).

### Self-Invention Lesson Learned & Mechanical Upstream Gate

- **Lesson Learned:** Self-built trading loops, shadow position/order trackers, custom rate-pacer classes, and arbitrary engine LOC-golfing obscured real `NautilusTrader v2` semantics. All shadow engine classes and LOC caps are permanently forbidden.
- **Mechanical Upstream Gates:** `rules/zero_self_invention.yml` (`no-self-built-trading-engine-class`, `no-custom-shadow-engine-wrapper-class`, `no-risk-engine-bypass`, `no-raw-http-broker-polling`, `no-polling-sleep-loop-in-src`), `tests/test_core_engine.py`, and `scripts/nautilus_mcp_server.py --smoke` (`run_prewall_native_backbone_parity`).

### Compounding Layer Integration

- Drives both `sim-backtest` (`BacktestEngine` + `hftbacktest` markout -> `MLflow`) and `live` (`LiveNode`/`SANDBOX` parity witnesses -> promotion dossier), guaranteeing that every compounding improvement verified in simulation transfers faithfully into `paper` and Stage-5 `live`.
