# ADR-0016: Institutional Backtesting, Microstructure Queue Simulation, 6-Gate Falsification & Sim==Paper==Live Trading Foundation

## Context and Problem Statement

Quantitative strategies fail silently in live markets when historical backtesting, microstructure fill/queue modeling, risk boundary arithmetic, multiple-testing falsification, and paper/live execution run on separate codebases or ad-hoc Python loops. Realizing the Core Trading Philosophy (`PHILOSOPHY_COMPOUNDING_MANIFEST.json`) demands one deterministic execution kernel from research through live readiness, broker-compliant outside-RTH collared `LIMIT` entry parity ([ADR-0019](ADR-0019.md)), realistic queue-position markout simulation, mathematically proved `Decimal` risk bounds ([ADR-0005](ADR-0005.md)), `skfolio`+`Clarabel.rs` portfolio allocation, and independent cross-leg empirical statistical falsification.

This ADR **supersedes [ADR-0004](ADR-0004.md) (Superseded) and [ADR-0006](ADR-0006.md) (Superseded)** as the single authoritative record for `Sim == Paper == Live` execution parity, Rust `hftbacktest` queue simulation, and 6-gate statistical falsification, while keeping the immutable pure `Decimal` risk kernel standalone in [ADR-0005](ADR-0005.md).

## Decision Drivers

- Enforce true `Sim == Paper == Live` execution parity inside `NautilusTrader v2` (`BacktestEngine`, `BacktestNode` / `ParquetDataCatalog`, `Environment.SANDBOX`, `LiveNode`, `OrderEmulator`, `RiskEngineConfig` / `LiveRiskEngineConfig` with `bypass=False`), routing collared `LIMIT` entries outside `RTH` and reserving `MARKET` entries strictly for `RTH`.
- Eliminate touch-fill illusion via Rust `hftbacktest` queue-position and latency modeling (`RiskAdverseQueueModel`, `ProbQueueModel`, `L3FIFOQueueModel`, `IntpOrderLatency`).
- Preserve fail-closed `Decimal` and integer-tick risk bounds via exhaustive `z3-solver` SMT `UNSAT` refutation alongside bounded symbolic contract exploration (`CrossHair`) and `Hypothesis` fuzzing on immutable `src/tier0_sota/risk.py` ([ADR-0005](ADR-0005.md)).
- Enforce **"LLM as Outer Research Operator Only"** (`Glasserman & Lin, arXiv:2309.17322`): because pre-wall data (`<= 2026-10-15`) sits inside LLM training cutoffs, LLMs remain strictly in the outer research loop (`MLflow 3`, `Optuna`, `Dagster`, `Inspect AI`, `DSPy/GEPA`, `nautilus-engine` MCP) while the inner backtest signal/execution kernel stays 100% deterministic (`NautilusTrader v2` + `hftbacktest`).
- Falsify `LONG` and `SHORT` legs independently across 6 statistical gates evaluating all per-leg gate booleans once on **raw unrounded finite floats** (zero display-rounding flips): requiring true `>= 16` OOS **paths** (`skfolio` `n_folds=8, n_test_folds=3` = `56` splits / `21` OOS paths, `cpcv_min_samples = 48` with fail-closed `DISCARD_INSUFFICIENT_PATHS` below `48`), independent raw Newey-West HAC Gate 6 checking against the project's **HLZ-inspired one-sided Bonferroni normal critical value** on both `1x` and `2x` legs, and Gate 1 `min_l1_fills = 16` when L1 markout evidence is supplied, with live operations following the three tiers of [ADR-0029](ADR-0029.md) (`live_execution_enabled = False` means tier 3 is off).
- Uphold strict OSI SPDX compliance across all pinned and frontier (`L13`/`L15`) upstreams (`peernagy/LOBS5` permanently pruned under `spdx_license_firewall`, enforced mechanically via `just license-audit` wired into `just security` admitting ONLY `LGPL-3.0-only` for `nautilus-trader` across installed venv wheels).

## Considered Options

1. **Disconnected Python bar loops, float stop math, hardcoded PBO shortcuts, and single-path Sharpe reporting** — breaks `Sim == Paper == Live` parity, overstates limit fill probability, exposes sub-dollar stops to rounding breaches, and masks selection bias.
2. **Unified `NautilusTrader v2` Rust Core + Rust `hftbacktest` Queue Simulation + Standalone Immutable `risk.py` ([ADR-0005](ADR-0005.md)) + 6-Gate Independent-Leg Empirical Falsification & `skfolio`/`Clarabel.rs` Portfolio Pipeline (chosen)**.

## Decision Outcome

Adopt Option 2 across `src/tier0_sota/engine.py`, `src/tier0_sota/research.py`, `src/tier0_sota/risk.py` (immutable, [ADR-0005](ADR-0005.md)), `evals/formal_risk_z3.py`, and `scripts/run_compounding_reflection.py` (superseding [ADR-0004](ADR-0004.md) (Superseded) and [ADR-0006](ADR-0006.md) (Superseded)):

1. **`Sim == Paper == Live` Execution & Venue Parity (`src/tier0_sota/engine.py`):**
   - `SignalExecutionStrategy` runs unified 24/5 session classification (`XNYS`), `RTH` `MARKET`/`STOP_MARKET` vs `outside_rth` collared `LIMIT` entries (`35 bps` Pre/After, `50 bps` Overnight, [ADR-0019](ADR-0019.md)) and collared `STOP_LIMIT` exits (`IBOrderTags:{"outsideRth":true}`), `POOLED_TRAILING_SCHEDULES`, 4-tier progressive trailing ([ADR-0007](ADR-0007.md)), flatten-first auto-reverse, `60s` rapid re-entry, native 5-minute internal bar aggregation, and `_guard_unprotected` failsafe exits.
   - `run_nautilus_signal_backtest` executes on `BacktestEngine` (`MakerTakerFeeModel`, `BarDataWrangler`, `MarketRegimeActor`); `build_sandbox_live_node` instantiates `LiveNode` in `Environment.SANDBOX`. `EXECUTION_VENUE_PROFILES` (`IBKR_PAPER_4002` `3,000 rpm`, `ALPACA_PAPER_200` `200 rpm`) refuses the unwired `IBKR_LIVE_3000` and `ALPACA_LIVE_ELITE_SMART_ROUTER` profiles and live ports (`4001`, `7496`, `8798`, `8796`); `ALPACA_LIVE_PRO_LINE_1000` follows the three tiers of [ADR-0029](ADR-0029.md) (`live_execution_enabled = False` means tier 3 is off).
2. **Microstructure Queue & Latency Simulation (`src/tier0_sota/research.py`):**
   - `evaluate_hftbacktest_queue_markout` replays causal pre-wall L1 quotes/trades (`<= 2026-10-15`, `FEED_LATENCY_NS = 50_000`, `constant_order_latency(100_000, 100_000)`) on Rust `hftbacktest` (`RiskAdverseQueueModel`) for passive `GTX` limit orders; `_evaluate_l1_gate1(min_l1_fills=16)` enforces `passive_order_submitted=True`, `passive_fills >= 16`, and `markout_bps >= -20.0` whenever L1 evidence is supplied, and scales to L2/L3 upon Tier B promotion ([ADR-0013](ADR-0013.md)).
3. **6-Gate Independent-Leg Empirical Falsification & `skfolio`/`Clarabel.rs` Portfolio (`src/tier0_sota/research.py`):**
   - `evaluate_six_gate_falsification` and `falsify_trade_returns` evaluate `COMBINED`, `LONG`, and `SHORT` legs independently using `skfolio.model_selection.CombinatorialPurgedCV(n_folds=8, n_test_folds=3, purged_size=2, embargo_size=2)` (`56` splits / **`21` OOS paths `>= 16`**, verified `cpcv_min_samples() = 48`), failing closed as `DISCARD_INSUFFICIENT_PATHS` (`cpcv_splits=0`, `cpcv_oos_paths=0`, still reporting DSR/HAC/SPA/MinTRL) whenever `< 48` trades, and exposing split distribution (`cpcv_oos_splits_min_bps`, `cpcv_oos_splits_median_bps`, `cpcv_oos_splits_p05_bps`).
   - All per-leg gate booleans (`gate_checks`) are evaluated **once from raw unrounded finite floats** before display rounding (preventing display-rounding boundary flips such as `2.99996 -> 3.0000`): Gate 1 (`_evaluate_l1_gate1`, `>= 16` passive fills when L1 supplied), Gate 2 (`1x`/`2x` return & mean `> 0`, `>= 16` trades), Gate 3 (`>= 16` OOS paths & CPCV OOS mean `> 0`), Gate 4 (`ml4t-diagnostic` DSR `>= 0.95`, MinTRL met, empirical PBO `< 0.50`), Gate 5 (`arch.bootstrap.SPA` consistent & upper `p < 0.05`), and explicit Gate 6 checking raw Newey-West HAC `t` against the project's **HLZ-inspired one-sided Bonferroni normal critical value** (`NormalDist().inv_cdf(1.0 - 0.00135 / n_t)`) on both `1x` and `2x` legs (`gate6_hac_t_1x`, `gate6_hac_t_2x`, `gate6_hurdle`).
   - `compute_skfolio_portfolio_weights(...)` allocates sleeve weights via `skfolio.optimization` (`MeanRisk` / `HierarchicalRiskParity`) on `Clarabel.rs` (`clarabel==0.11.1`).
4. **Formal Immutable Risk Kernel Binding ([ADR-0005](ADR-0005.md)):** All stop clamping, sizing, drawdown latching, and rate-budget preservation delegate unconditionally to `src/tier0_sota/risk.py`.
5. **Pre-Sunday Fine-Tuning Execution Order (P0 -> P1/P2):** With P0 parity fixes (`8/3` 21-path CPCV, unrounded raw Gate-6/Gate-1 enforcement, and `discovery.py`/`scanner.py` RVOL parity) landed, any new empirical strategy cycle (such as candidate `H110`: regime `-1` passive `SHORT`/inverse ETF) must **preregister the hypothesis JSON (including trial increment and power rule) strictly before** running widened `594`-session catalog / top-100 universe calibration runs, preserving strict trial accounting under [ADR-0020](ADR-0020.md).

## Consequences

- **Positive:** Delivers one end-to-end `NautilusTrader v2` + `hftbacktest` + `Z3` + `skfolio`/`Clarabel.rs` + empirical 6-gate falsification foundation where simulation, sandbox, paper, and Stage-5 readiness share identical collared 24/5 order and risk semantics.

## Pros and Cons of the Options

### Option 1: Disconnected Python bar loops + float math + hardcoded PBO shortcuts

- Good, because early experiments run quickly in plain Python.
- Bad, because backtest fills diverge from live brokers, float rounding violates stop bounds, and hardcoded PBO masks selection bias.

### Option 2: Unified `NautilusTrader v2` + Rust `hftbacktest` + `risk.py` + empirical 6-gate falsification + `skfolio`/`Clarabel.rs`

- Good, because one verified OSI Rust/Python stack enforces `Sim == Paper == Live` parity, queue-tail realism, formal `Decimal` safety, conic portfolio weighting, and multiple-testing rigor across independent legs.
- Bad, because strategies need `>= 16` pre-wall trades per leg to clear CPCV and must track `NautilusTrader 2.0` pre-release APIs until GA.
