# ADR-0016: Institutional Backtesting, Microstructure Queue Simulation, 6-Gate Falsification & Sim==Paper==Live Trading Foundation

## Context and Problem Statement

Quantitative strategies fail silently in live markets when historical backtesting, microstructure fill/queue modeling, risk boundary arithmetic, multiple-testing falsification, and paper/live execution run on separate codebases or ad-hoc Python loops. Realizing the Core Trading Philosophy (`PHILOSOPHY_COMPOUNDING_MANIFEST.json`) — entering extreme movers early, aligning direction with causal multi-feed market regime (`SPY`, `QQQ`, `SOXX`, `RSP`, `VIX`), protecting every order 24/5 with near-lossless `BE+fee` + 4-tier progressive profit-lock trailing, flatten-first climax auto-reverse, and `60s` rapid re-entry — demands one deterministic execution kernel from research through live readiness, realistic queue-position markout simulation, mathematically proved `Decimal` risk bounds ([ADR-0005](ADR-0005.md)), and independent cross-leg statistical falsification.

This ADR **supersedes [ADR-0004](ADR-0004.md) (Superseded) and [ADR-0006](ADR-0006.md) (Superseded)** as the single authoritative record for `Sim == Paper == Live` execution parity, Rust `hftbacktest` queue simulation, and 6-gate statistical falsification, while keeping the immutable pure `Decimal` risk kernel standalone in [ADR-0005](ADR-0005.md).

## Decision Drivers

- Enforce true `Sim == Paper == Live` execution parity inside `NautilusTrader v2` (`BacktestEngine`, `BacktestNode` / `ParquetDataCatalog`, `Environment.SANDBOX`, `LiveNode`, `OrderEmulator`, `RiskEngineConfig` / `LiveRiskEngineConfig` with `bypass=False`).
- Eliminate touch-fill illusion via Rust `hftbacktest` queue-position and latency modeling (`RiskAdverseQueueModel`, `ProbQueueModel`, `PowerProbQueueModel`, `LogProbQueueModel`, `L3FIFOQueueModel`, `IntpOrderLatency`).
- Preserve fail-closed `Decimal` and integer-tick risk bounds (`<= 2.00%` Reg-NMS Rule-612 stop, `-1.50%` session-latched drawdown fuse, `>= 10%` protective-exit rate reserve) proved via `z3-solver` (`UNSAT`) and `Hypothesis` on immutable `src/tier0_sota/risk.py` ([ADR-0005](ADR-0005.md)).
- Falsify `LONG` and `SHORT` legs independently across 6 statistical gates (`1x`/`2x` costs, L1 markout, `skfolio` `CombinatorialPurgedCV` with `MIN_CPCV_SAMPLES = 16`, `ml4t-diagnostic` DSR / MinTRL / PBO, `arch` Hansen SPA, `statsmodels` Newey-West HAC) with `live_execution_enabled = False` and `paper_only = True` until Stage-5 promotion ([ADR-0020](ADR-0020.md)).
- Uphold strict OSI SPDX compliance across all pinned and frontier (`L13`/`L15`) upstreams with zero non-OSI licenses per `spdx_license_firewall` in `upstream-map.toml` (explicitly pruning unlicensed `peernagy/LOBS5`).

## Considered Options

1. **Disconnected Python bar loops, float stop math, and single-path Sharpe reporting** — breaks `Sim == Paper == Live` parity, overstates limit fill probability, exposes sub-dollar stops to rounding breaches, and masks selection bias (`PBO` / data snooping).
2. **Unified `NautilusTrader v2` Rust Core + Rust `hftbacktest` Queue Simulation + Standalone Immutable `risk.py` ([ADR-0005](ADR-0005.md)) + 6-Gate Cross-Leg Falsification Pipeline** — anchors every execution, validation, and risk path inside verified OSI upstreams (`L3`, `L5`, `L7`) with deterministic `MLflow`/`Optuna` compounding and OSI-clean `L13`/`L15` frontier readiness.

## Decision Outcome

Adopt Option 2 across `src/tier0_sota/engine.py`, `src/tier0_sota/research.py`, `src/tier0_sota/risk.py` (immutable, governed standalone by [ADR-0005](ADR-0005.md)), `evals/formal_risk_z3.py`, and `scripts/run_compounding_reflection.py` (superseding [ADR-0004](ADR-0004.md) (Superseded) and [ADR-0006](ADR-0006.md) (Superseded)):

1. **`Sim == Paper == Live` Execution & Venue Parity (`src/tier0_sota/engine.py`):**
   - `SignalExecutionStrategy` (`Strategy` / `StrategyConfig`) runs identical 24/5 session classification (`engine.classify_et_hm`, `engine.classify_us_equity_session_et` via `XNYS`), `RTH` `STOP_MARKET` vs collared `outside_rth` `STOP_LIMIT` (`IBOrderTags:{"outsideRth":true}` with `35 bps` pre/after-hours and `50 bps` overnight collars), `POOLED_TRAILING_SCHEDULES`, 4-tier progressive trailing ([ADR-0007](ADR-0007.md)), flatten-first auto-reverse, `60s` rapid re-entry, native 5-minute internal bar aggregation, and `_guard_unprotected` failsafe exits (tracked off-hours entry `LIMIT` remediation in [ADR-0019](ADR-0019.md)).
   - `run_nautilus_signal_backtest` executes on `BacktestEngine` (`MakerTakerFeeModel`, `BarDataWrangler` from Polars IPC stream with causal `ts_event = t_ns + 60s`, and `MarketRegimeActor`); `build_sandbox_live_node` instantiates `LiveNode` in `Environment.SANDBOX` (`SandboxExecutionClientConfig`); multi-symbol disk streaming adopts `NautilusTrader v2` `BacktestNode` + `ParquetDataCatalog`.
   - `EXECUTION_VENUE_PROFILES` (`IBKR_PAPER_4002` `3,000 rpm`, `ALPACA_PAPER_200` `200 rpm`) wires native `RiskEngineConfig` / `LiveRiskEngineConfig` (`bypass=False`), refuses all `LIVE` profiles (`IBKR_LIVE_3000`, `ALPACA_LIVE_PRO_LINE_1000`, `ALPACA_LIVE_ELITE_SMART_ROUTER`) via `PermissionError`, and restricts `build_ibkr_paper_connection_spec` to paper ports `:4002` / `:7497` (`FORBIDDEN_LIVE_IBKR_PORTS = {4001, 7496, 8798, 8796}`).
2. **Microstructure Queue & Latency Simulation (`src/tier0_sota/research.py`):**
   - `evaluate_hftbacktest_queue_markout` replays causal pre-wall L1 quotes/trades (`<= 2026-10-15`, `FEED_LATENCY_NS = 50_000`, `constant_order_latency(100_000, 100_000)`) on Rust `hftbacktest` (`HashMapMarketDepthBacktest`) with `RiskAdverseQueueModel`, `no_partial_fill_exchange`, and `trading_value_fee_model` for passive `GTX` limit orders.
   - Higher-granularity L2 MBP and L3 MBO research scales natively inside `hftbacktest` via `ProbQueueModel`, `PowerProbQueueModel`, `LogProbQueueModel`, `L3FIFOQueueModel`, and `IntpOrderLatency` once Tier B depth promotes under [ADR-0013](ADR-0013.md).
3. **6-Gate Cross-Leg Statistical Falsification (`src/tier0_sota/research.py`):**
   - `evaluate_six_gate_falsification` and `falsify_trade_returns` evaluate combined, `LONG`, and `SHORT` legs independently, failing closed as `DISCARD_INSUFFICIENT_TRADES` whenever `n_trades < MIN_CPCV_SAMPLES` (`16`):
     - `1_hftbacktest_l1_markout`: passive `GTX` limit submitted and `markout_bps >= -20.0`.
     - `2_cost_1x_2x_survival`: positive net return and `PROMOTE` across `1x` (`4.0 bps`/side) and `2x` (`8.0 bps`/side) costs (re-run at empirically measured paper cost under [ADR-0019](ADR-0019.md)).
     - `3_cpcv_oos_positive`: `skfolio` `CombinatorialPurgedCV(n_folds=4, n_test_folds=2, purged_size=1, embargo_size=1)` yields `6` OOS paths with positive mean bps on both `1x` and `2x`.
     - `4_dsr_pbo_credible`: `ml4t-diagnostic` `deflated_sharpe_ratio_from_statistics` `>= 0.95` at true cumulative `n_trials_total`, `n_trades >= min_trl` (`compute_min_trl`), and `compute_pbo` `< 0.50`.
     - `5_hansen_spa_significant`: `arch.bootstrap.SPA` (`block_size=2, reps=300`) consistent and upper `p < 0.05`.
     - `6_hac_t_stat_significant`: `statsmodels` Newey-West HAC `OLS` t-statistic clears the multiple-testing Harvey-Liu-Zhu threshold `NormalDist().inv_cdf(1.0 - 0.00135 / n_t)`.
4. **Formal Immutable Risk Kernel Binding ([ADR-0005](ADR-0005.md)):** All stop clamping, sizing, drawdown latching, and rate-budget preservation delegate unconditionally to `src/tier0_sota/risk.py` (`SHA-256 ad8071dcd4196c4c529c02107114ebfdda6692bc9d7c220031f1b19ea3e4d847`).

## Consequences

- **Positive:** Delivers one end-to-end `NautilusTrader v2` + `hftbacktest` + `Z3` + 6-gate falsification foundation where simulation, sandbox, paper, and Stage-5 readiness share identical risk and protection semantics while eliminating duplicate execution/falsification ADRs.
- **Negative:** Requires maintaining strict parity across `NautilusTrader 2.0.0rc9`, `hftbacktest 2.4.4`, and `risk.py` SHA-256 without introducing shadow engine wrappers or float arithmetic.

## Pros and Cons of the Options

### Option 1: Disconnected Python bar loops + float math + single-path Sharpe

- Good, because early experiments run quickly in plain Python.
- Bad, because backtest fills diverge from live brokers, float rounding violates stop bounds, and selection bias passes unflagged.

### Option 2: Unified `NautilusTrader v2` + Rust `hftbacktest` + `risk.py` + 6-gate falsification

- Good, because one verified OSI Rust/Python stack enforces `Sim == Paper == Live` parity, queue-tail realism, formal `Decimal` safety, and multiple-testing rigor across independent legs.
- Bad, because strategies need `>= 16` pre-wall trades per leg to clear CPCV and must track `NautilusTrader 2.0` pre-release APIs until GA.

### Self-Invention Lesson Learned & Mechanical Upstream Gate

- **Lesson Learned:** Self-built simulation loops, custom shadow `OrderManager`/`RatePacer` wrappers, arbitrary LOC caps, `float()` casts in risk boundaries, transitive pulls of `quantstats`/`yfinance`, and admitting unlicensed academic code (`peernagy/LOBS5` without a root OSI `LICENSE`) degraded reliability and compliance.
