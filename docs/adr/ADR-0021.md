# ADR-0021: Institutional Analytics UI, Real-Time 24/5 Trading Cockpit & Multimodal Quantitative Workbench (`L10`)

- **Status:** Accepted
- **Date:** 2026-11-26
- **Evidence Grade:** E4
- **Sole Source of Truth:** SOTA upstream convergence per Core Trading Philosophy

## Context and Problem Statement

Operating a 24/5 quantitative trading and research workstation across four compounding harness lanes (`sim-backtest`, `paper`, `half-auto-tv`, `live`) requires institutional-grade visual analytics: multi-lane paper equity and drawdown telemetry, real-time extreme-mover watchlists and staged order tickets, high-density streaming blotters, sub-second SQL inspection over `DuckDB` and pre-wall Parquet lakes, and unmodified backtest/SHAP tearsheets.

Left unconstrained, quantitative repositories routinely accumulate five high-friction UI anti-patterns:

1. **Hand-Written Dashboard & Web-Server Drift:** Bespoke `FastAPI`/`Flask`/`Streamlit`/`Dash`/`Gradio`/`NiceGUI` apps or custom React/HTML/JS blotters under `src/` or `scripts/` duplicate upstream portals, introduce XSS/CSP and supply-chain exposure, bypass static Python gates, and drain engineering cycles away from alpha and execution quality.
2. **Inline-Python Static Server Shims:** Serving tearsheets via `python -m http.server` instead of an official static file server lacks hardened headers, deterministic health checks, and clean container isolation.
3. **Opaque, Unpinned Widget Extensions:** Loading unverified third-party frontend bundles or running ad-hoc SQL queries against workspace admin databases breaks auditability, secret hygiene, and plugin integrity.
4. **Browser Automation & Repainting Cockpit Violations:** Scraping or driving TradingView Desktop via CDP (`:9223`) or plotting repainting Pine indicators violates vendor ToU and corrupts `half-auto-tv` operator decisions.
5. **Commercial License Creep & Speculative Workbench Bloat:** Admitting commercial-EULA grid tiers (`AG Grid Enterprise`) or unverified frontier visualization frameworks without empirical bottlenecks violates the Tier-0 SPDX OSI License Firewall and bloats `uv.lock`.

While [ADR-0010](ADR-0010.md) governs the ToU-compliant TradingView Pine v6 + Pydantic v2 (`TvAlertV1`) half-auto bridge and [ADR-0017](ADR-0017.md) (superseding [ADR-0011](ADR-0011.md)) governs Disk-Z WSL2 hosting of the 15-portal stack, the `L10` institutional UI, declarative data-contract boundary, plugin governance model, and earned-trigger multimodal workbench evolution require a dedicated authoritative architecture decision record.

## Decision Drivers

- **Zero Hand-Written HTML/JS/TS or Web Servers in `src/` and `scripts/`:** Production Python and script trees emit pure declarative data contracts (JSON, Markdown, grouped watchlist text, Parquet, `DuckDB`, unmodified upstream tearsheet HTML) consumed exclusively by official upstream `L10` and `L6` platforms.
- **Strict SPDX OSI License Firewall:** Admit only OSI-approved licenses (`Apache-2.0`, `MIT`, `BSD-3-Clause`, `AGPL-3.0` run unmodified and loopback-only); exclude non-OSI source-available licenses and commercial-EULA tiers (specifically excluding `AG Grid Enterprise` while admitting MIT-licensed `ag-grid-community`).
- **Loopback-Only, Fail-Closed Safety Invariants:** Bind every `L10` portal strictly to `127.0.0.1` with zero live broker ports (`:4001`, `:7496`, `:8798`, `:8796`), `paper_only = True`, `live_execution_enabled = False`, `semi_auto_confirmed = False`, `qty = 1`, read-only data/manifest mounts, and zero modification to the immutable `Decimal` `src/tier0_sota/risk.py` kernel.
- **Checksum-Pinned Plugin & CLI Governance:** Manage FINOS Workspace widget plugins exclusively through official `scripts.plugin_check --digest`, `WIDGET_PLUGINS_PINS` (`WIDGET_PLUGINS_REQUIRE_PINS=true`), CSP/network overrides, RBAC role grants, and stdin-only secrets via `python -m scripts.workspace_admin`.
- **Earned-Trigger Multimodal Workbench Evolution:** Track emerging `L10`/`L14` visual workbenches (`marimo`, `rerun`, `mosaic`, `FDC3`, `evidence`) with verified SPDX licenses and explicit quantitative promotion triggers rather than speculative installation.

## Considered Options

1. **Custom `FastAPI`/`Streamlit`/`Dash` or Hand-Written React/HTML/JS Cockpit under `src/` and `scripts/`** — violates Zero Self-Invention (`no-custom-dashboard-server`, `no-handwritten-web-assets`), duplicates upstream institutional UI engines, and creates unmaintained frontend security debt.
2. **Commercial Proprietary Terminal / `AG Grid Enterprise` Bundle or TradingView CDP Browser Automation** — violates the SPDX OSI License Firewall (`AG Grid Enterprise` commercial EULA) or TradingView ToU (CDP `:9223` forbidden under [ADR-0010](ADR-0010.md)).
3. **Declarative-Contract `L10` Institutional Stack (`FINOS Workspace` `:1420`/`:8000` + `OpenBB` `:6900` + `finos/perspective` + `lightweight-charts` v5 + `ag-grid-community` + `DuckDB SQL UI` `:4213` + `Caddy` Tearsheets `:8793` + Display-Only Pine v6 Cockpit) with Zero Self-Edit UI Mechanical Gates and Earned-Trigger `L10`/`L14` Workbench Watches (`marimo`, `rerun`, `mosaic`, `FDC3`, `evidence`)**.

## Decision Outcome

Adopt **Option 3** as the authoritative `L10` Institutional Analytics UI, Real-Time 24/5 Trading Cockpit, and Multimodal Quantitative Workbench architecture, reinforcing [ADR-0001](ADR-0001.md), [ADR-0009](ADR-0009.md), [ADR-0010](ADR-0010.md), [ADR-0017](ADR-0017.md), and [ADR-0018](ADR-0018.md).

### 2. Real-Time 24/5 Trading Cockpit & Declarative Data Contracts

Zero UI code lives inside `src/tier0_sota/`. Instead, production Python emits strictly validated, atomically written declarative JSON, Markdown, and TradingView watchlist artifacts consumed by the upstream portals:

- **Paper Farm Performance & FINOS/OpenBB Contract (`src/tier0_sota/live/performance.py`):**
  - `PaperPerformanceAggregator` reads isolated per-lane status manifests (`<account>_live_automation_status.json`) and snapshots each lane's `DuckDB` ledger via a temporary copy (`shutil.copy2` + `duckdb.connect(..., read_only=True)`) so UI/telemetry reads never contend with live paper writers.
  - Aggregates across all 4 symbolic accounts (`ALPACA_PA1` `L1_ORB_BURST`, `ALPACA_PA2` `L2_STRUCTURAL_TREND`, `ALPACA_PA3` `L3_AVWAP_TIGHT_LOCK`, `IBKR_DU_4002` `IBKR_SMART_24X5`) in `Polars` and atomically writes two manifests under `Z:\sota-data\manifests\`:
    1. `paper_farm_live_performance_manifest.json` (`schema_version: "tier0.paper-farm-live-performance.v1"`, `paper_only: true`, `live_execution_enabled: false`, `paper_live_deployed: false`).
    2. `finos_paper_farm_performance.json` (`schema_version: "tier0.finos-openbb-paper-farm.v1"`, `plugin: "@finos-workspace/plotly-charts@2.5.0"`, `paper_only: true`, `live_execution_enabled: false`) carrying declarative Plotly bar `data`/`layout` plus tabular `openbb_rows` and combined `summary`.
- **24/5 Half-Auto TradingView Cockpit (`src/tier0_sota/tv/{bridge,tickets}.py`, `pine/*.pine`, `scripts/tv_console.ps1`):**
  - `tv/bridge.py` enforces the strict Pydantic v2 `TvAlertV1` contract (`ConfigDict(extra="forbid")`, `Decimal` prices/NATR, bool-rejection validators, aligned with Draft 2020-12 `src/tier0_sota/tv/schema_v1.json`), hard-refusing live endpoints (`4001`, `7496`, `8798`, `8796`, `api.alpaca.markets`), requiring `bar_confirmed=True`, `qty=1`, `semi_auto_confirmed=False`, `MAX_INPUT_AGE_MS = 900_000` (15m), `XNYS` 24/5 session parity (`engine.classify_us_equity_session_et`), exact Rule-612 inward stops (`<= 2.00%`), NATR-matched `3x4` trailing schedule parity, and affirmative `shortable && easy_to_borrow` watchlist evidence for `SELL` alerts.
  - `tv/tickets.py` filters whole-market movers to extreme movers (retaining inverse crash hedges `SOXS`/`SQQQ` when `macro_regime == -1`), validates every ticket against `TvAlertV1`, computes exact `Decimal` Rule-612 rungs (`stop_now`, `stop_rth_0930`, `be_plus_fee_floor` `+10 bps`, `lock_at_1r` `+0.45R`, `lock_at_2r` `+1.35R`, `fast_sell_rev_trigger` `40 bps` adverse), sizes defensive `$25k`/`$100k` positions (`0.25%` risk in crash regime vs `0.50%` otherwise, `15%` max notional), routes non-ETB shorts to `INVERSE_HEDGE_SOXS_SQQQ`, and atomically writes `live_half_auto_tickets.json` (`schema_version: "tier0.live-half-auto-tickets.v1"`), `LIVE_HALF_AUTO_ORDER_TICKETS.md`, and 4-section `tier0_sota_tv_watchlists_live.txt` (`01_MACRO_REGIME_BREADTH`, `02_CRASH_DEFENSIVE_HEDGES`, `03_LIVE_MOVERS_TOP15`, `04_BIDIRECTIONAL_PAIRS`) to `Z:\sota-data\manifests\tv_sota_pack\`.
  - `scripts/tv_console.ps1` provides zero-CDP clipboard and portal helpers (`tv-tickets`, `tv-stage`, `tv-copy-omni`, `tv-copy-regime`, `tv-copy-watchlist`, `tv-portals` launching `:1420`, `:3001`, `:3000`, `:8793`, and `tv-e2e`).
- **Observability Companion (`L6`):** `Grafana` (`:3001`, declarative `docker/grafana/dashboards/tier0-sota-observability.json`), `Prometheus` (`:9090`), and `otel/opentelemetry-collector-contrib:0.123.0` (`:9464/metrics`, `:13133`) remain strictly declarative JSON/YAML companion surfaces under [ADR-0017](ADR-0017.md).

### 3. Plugin Governance, Sandboxing & Zero Self-Edit UI Enforcement

- **FINOS Workspace Plugin Lifecycle (`.claude/skills/finos-develop-plugins/SKILL.md` & `finos-administer-via-cli/SKILL.md`):**
  - Widget plugins live exclusively in external upstream repositories under `Z:\sota-data\hosted-research-frameworks\finos-workspace-plugins` (mounted `:ro` in `compose.sota.yml`) and host-bound `widget-plugins/<plugin-id>/<version>/` — never inside `Z:\noesis\src/` or `scripts/`.
  - Every package conforms to `manifestVersion: 1`, `host: {"api": 1, "afm": "0.11"}`, closed manifest keys (no unknown keys, max 200 files / 64 MiB, `plugin.json` `<= 256 KiB`), and SHA-256 verification via `python -m scripts.plugin_check --digest`, pinned in production via `WIDGET_PLUGINS_PINS` and `WIDGET_PLUGINS_REQUIRE_PINS=true`.
  - Administrative actions (`rescan`, `show`, `approve --digest <D> --acknowledge`, `enable`, `grant`, `override`, `revoke`, `check-backend`, `reports`) execute strictly through `python -m scripts.workspace_admin --json` rather than direct SQL; plugin secrets enter exclusively via non-TTY stdin (`plugin secret set`) or `WIDGET_PLUGIN_SECRETS_DIR` files (never CLI argv or `.env` leaks).
- **Lightweight Charts v5 Discipline (`.claude/skills/lightweight-charts/SKILL.md`):**
  - Any official upstream chart widget targeting `lightweight-charts` v5 must use v5 tree-shaken APIs (`chart.addSeries(SeriesType, options, paneIndex?)`, `createSeriesMarkers`, `createTextWatermark`, `IPanePrimitive`/`IPrimitivePaneRenderer` + `fancy-canvas`), pass `UTCTimestamp` in **seconds** (never milliseconds), format `America/New_York` via DST-safe `Intl.DateTimeFormat` formatters rather than shifting bar timestamps, and stream ticks via `series.update(bar)` instead of `setData`.

### Self-Invention Lesson Learned & Mechanical Upstream Gate

- **Lesson Learned:** Earlier workstation iterations relied on ad-hoc Python HTTP server shims (`python -m http.server` for tearsheets), inline-Python fake Prometheus metrics scripts, and temptation to embed bespoke web dashboards inside Python source trees — each causing recurring drift, missing headers, and unguarded dependency creep. Replacing all custom UI and HTTP shims with official upstream `FINOS Workspace`, `OpenBB`, `DuckDB UI`, `Caddy`, `Grafana`, and `OTel Collector` fed strictly by declarative JSON/Parquet/DuckDB contracts eliminated frontend maintenance burden inside `noesis`.
- **Mechanical Upstream Gates:**
  - `rules/zero_self_invention.yml` (`ast-grep`, 21 rules): `no-custom-dashboard-server` blocks `fastapi`, `starlette`, `flask`, `dash`, `gradio`, `nicegui`, `panel`, `bokeh`, `uvicorn`, `quart`, `sanic`, `tornado`, `http.server`, `HTTPServer`, `SimpleHTTPRequestHandler`, and `HTMLResponse` across `src/**/*.py` and `scripts/**/*.py`; `no-banned-library-import` blocks `streamlit`; `no-raw-http-socket-in-src`, `no-live-broker-endpoint`, and `no-hardcoded-live-execution-true` enforce fail-closed boundaries.
  - `.pre-commit-config.yaml` (`prek` hooks): `no-handwritten-web-assets` (`language: fail`, regex `^(src|scripts)/.*\.(html?|[cm]?[jt]sx?)$`) mechanically blocks any HTML, JS, JSX, TS, or TSX file from entering `src/` or `scripts/`; `no-tracked-notebook` blocks `.ipynb` commits; `gitleaks` blocks secrets, home paths, and raw broker account IDs.
  - `upstream-map.toml` (`banned_packages` + `layers.L10.rejected_overlaps`): forbids `streamlit`, `dash`, `gradio`, `nicegui`, `quantstats`, and `custom-react-blotter` in `uv.lock`.
  - `tests/test_live_automation.py`, `tests/test_tv_automation.py`, `tests/test_grand_reset_kit.py` (verifying `compose.sota.yml` read-only mounts, zero live ports, `Server: Caddy`, and MADR sections), `scripts/preflight_resume.{ps1,sh}` (`local_portals_15` + `wsl_systemd_services`), and `uv run --no-sync zensical build --clean --strict`.
