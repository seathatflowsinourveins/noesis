# ADR-0023: LLM-Native Zero-Friction Secret Automation with `jdx/fnox` + `age` Profiles & Cross-OS WSL2/Windows Parity

- **Status:** Accepted
- **Date:** 2026-11-26
- **Evidence Grade:** E4
- **Sole Source of Truth:** SOTA upstream convergence per Core Trading Philosophy
- **Related:** [ADR-0001](ADR-0001.md) (Architecture Layers `L0..L10` & Zero Self-Invention), [ADR-0012](ADR-0012.md) (AAIF `AGENTS.md` SSOT & Grand-Reset), [ADR-0017](ADR-0017.md) (Native Workstation Hosting & 15-Portal Stack), [ADR-0018](ADR-0018.md) (Multi-Model Agentic Harness & OmniRoute), [ADR-0022](ADR-0022.md) (AGY 2.0 Zero-Copy Skills & Windows/WSL2 Companion Topology)

## Context and Problem Statement

Prior to this decision, paper-trading broker credentials and market-data keys were split awkwardly across OS-specific mechanisms:

1. **Custom WSL2 Wrapper & Plaintext Dotfiles:** `scripts/grand_reset/01_wsl_bootstrap.sh` generated a hand-rolled `~/.config/tier0/with_lane_env.sh` helper and plaintext `~/.config/tier0/.env.{data,paper}` files on Linux, duplicating secret handling outside `mise`/`just` and forcing bespoke shell sourcing on every invocation.
2. **Windows-Side Credential Friction:** On Windows 11, running `just scan` or `just automate` skipped live Alpaca SIP scans whenever `ALPACA_PA1_API_KEY` or `APCA_API_KEY_ID` was not manually exported into the active process environment, blocking frictionless cross-OS automation across Windows Desktop AGY (primary) and WSL2 Linux AGY Desktop (`2.35.2`) + `agy` CLI (`1.5.18`) (companion).
3. **LLM Safety & Secret Hygiene:** Multi-agent coding workflows (`Antigravity`, `Orca`, `Claude Code`, `Codex`, `Gemini CLI`, `OpenCode`) require declarative, auditable secret profiles where agents can execute `fnox exec --profile paper -- ...` and inspect `fnox.toml` schema without ever viewing, printing, or risking plaintext secret leakage into git history or logs, while keeping dormant Stage-5 live credentials physically isolated from paper keys.

## Decision Drivers

- **Upstream-Only `L0` Secret Management (`jdx/fnox` + `FiloSottile/age`):** Adopt `fnox@1.50` and `age@1.3` directly via `mise.toml` (same `jdx` ecosystem as `mise`) with encrypted `age` ciphertexts committed safely in `fnox.toml` and private keys kept strictly outside the repository (`~/.config/fnox/age.txt` / `$FNOX_AGE_KEY_FILE`).
- **Zero-Friction Cross-OS Execution Parity:** Ensure `just scan`, `just paper-farm`, `just automate`, and `just fnox-check` resolve encrypted paper/data credentials identically on Windows 11 (`pwsh`) and WSL2 `Noesis-SOTA` (`bash`) while degrading gracefully (`[SKIP]`) in unauthenticated CI runners.
- **Physical Isolation of Dormant Stage-5 Live Keys:** Keep `[profiles.live]` bound to a separate provider (`age_live`) and intentionally absent key file (`~/.config/fnox/live-age.txt`) with `LIVE_EXECUTION_ENABLED = { default = "false" }`, preserving fail-closed `paper_only = True` invariants until full Stage-5 promotion.
- **WSL2 AGY Full `L0..L10` Convergence & Retirement of Custom Wrappers:** Expose `~/.local/share/mise/shims`, `FNOX_AGE_KEY_FILE`, and zero-copy `~/.gemini/config/skills.json` across WSL2 `Noesis-SOTA` login shells and `just open-agy-wsl`, permanently retiring `with_lane_env.sh` and plaintext `~/.config/tier0/.env.{data,paper}`.

## Considered Options

1. **Retain custom `~/.config/tier0/with_lane_env.sh` + plaintext `.env.{data,paper}` on WSL2 and manual Windows environment variables** — violates Zero Self-Invention, causes Windows/WSL2 drift, leaves plaintext keys on disk, and breaks zero-friction `just automate` runs.
2. **Adopt `SOPS` + external KMS or cloud-only secret vault** — adds unnecessary cloud/KMS runtime latency and operational coupling for a local-first single-workstation 24/5 paper farm.
3. **Adopt `jdx/fnox` (`1.50`) + `FiloSottile/age` (`1.3`) declarative encrypted profiles in `fnox.toml`, wired directly into `mise.toml`, `justfile`, `01_wsl_bootstrap.sh`, and `preflight_resume.sh`**.

## Decision Outcome

Adopt **Option 3** across `L0` toolchain manifests (`mise.toml`, `upstream-map.toml`, `SOTA_STARRED_AND_BEYOND_MANIFEST.json`, `scripts/sync_manifest.py`), `fnox.toml`, `justfile`, `scripts/grand_reset/01_wsl_bootstrap.sh`, and `scripts/preflight_resume.sh`:

### Declarative `fnox.toml` Profile Architecture

| Profile | Provider & Key File | Secrets / Defaults | Operational Boundary |
|---|---|---|---|
| `default` / `data` | `age` (`~/.config/fnox/age.txt` or `$FNOX_AGE_KEY_FILE`) | `APCA_API_KEY_ID`, `APCA_API_SECRET_KEY`, `EDGAR_IDENTITY` (`age` ciphertexts); optional `FRED_API_KEY` (`if_missing = "ignore"`) | Market data, SEC filings, and PIT research feeds |
| `paper` | Inherits `age` provider & default secrets | `ALPACA_PA1..PA3` API keys & secrets (`6` `age` ciphertexts) + defaults `ALPACA_PAPER="true"`, `IBKR_HOST="127.0.0.1"`, `IBKR_PORT="4002"` | Stationary 4-account Paper Farm & live SIP mover scans (`paper_only = True`) |
| `live` (Dormant Stage-5) | Isolated `age_live` (`key_file = "~/.config/fnox/live-age.txt"`, intentionally absent) | `LIVE_EXECUTION_ENABLED = { default = "false" }`, `ALPACA_LIVE_API_KEY = { provider = "age_live", if_missing = "ignore" }` | Physically isolated and fail-closed until full Stage-5 promotion |

### Cross-OS `justfile`, WSL2 Bootstrap & AGY Convergence

- **`justfile` Recipes:** Add `just fnox-check` (`default`, `data`, `paper`, `live`), cross-OS `just scan` and `just paper-farm` automatically executing via `fnox exec --profile paper --` when `fnox` and the local `age` key exist (gracefully skipping unauthenticated CI scans), update `just automate` on both `[windows]` and `[unix]` to delegate to `just scan` and `just paper-farm`, and add cross-OS `just open-agy-wsl` to launch WSL2 Linux Antigravity Desktop (`2.35.2`) on `/mnt/z/noesis` via WSLg alongside Windows primary `just open-agy`.
- **WSL2 Bootstrap (`scripts/grand_reset/01_wsl_bootstrap.sh`):** Stop generating custom `with_lane_env.sh` and plaintext `.env.{data,paper}` placeholders; remove stale `with_lane_env.sh`; ensure `~/.config/fnox` (`chmod 700`), export `FNOX_AGE_KEY_FILE` and `~/.local/share/mise/shims` in `# >>> noesis env >>>`; and idempotently write zero-copy `~/.gemini/config/skills.json` pointing to `/mnt/z/noesis/.claude/skills`.
- **WSL2 Preflight (`scripts/preflight_resume.sh`):** Preserve all `13/13` always-on gates while enriching gate #8 (`agy_native_mcp_config`) telemetry with WSL2 `skills_json` and `fnox` readiness (`ready` / `config_only` / `absent`).

## Consequences

- **Positive:** Eliminates custom secret wrapper scripts and plaintext `.env.{data,paper}` files on disk, enables single-command cross-OS live Alpaca SIP scanning and Paper Farm orchestration (`just scan`, `just paper-farm`, `just automate`), keeps zero plaintext credentials in git (`gitleaks` and `trivy` clean with zero blanket allowlists), physically isolates dormant Stage-5 live credentials, and unifies WSL2 AGY Desktop (`2.35.2`) + `agy` CLI (`1.5.18`) with the full `L0..L10` toolchain.
- **Negative:** Operators setting up a brand-new workstation must provision their out-of-band `age` identity at `~/.config/fnox/age.txt` (or `$FNOX_AGE_KEY_FILE`) before encrypted profiles decrypt locally, and key rotation requires re-encrypting `fnox.toml` entries via `fnox set`.

## More Information

### Upstream Evidence & Empirical Benchmarks

- **Cross-OS Verification:** `fnox 1.50.0` + `age v1.3.2` installed via `mise` on both Windows 11 and WSL2 `Noesis-SOTA` pass `fnox check` across all 4 profiles (`default`, `data`, `paper`, `live`), decrypt all 9 encrypted keys identically via `fnox exec --profile paper` with identical public recipient `age18p7ze4w2qge89gcd8cdk25ym6upg0fmyy9azz4hhys8a4kpmwsvqqp7p7z`, and drive live Alpaca SIP whole-market extreme-mover scans cleanly via `just scan`.
- **Zero-Secret Security Verification:** `gitleaks detect --no-git --source . --config .gitleaks.toml --no-banner` (`0` leaks) and `trivy fs --scanners misconfig,secret --severity HIGH,CRITICAL` (`0` findings) pass cleanly on committed `fnox.toml` `age` ciphertexts with zero rule relaxations.

### Self-Invention Lesson Learned & Mechanical Upstream Gate

- **Lesson Learned:** Hand-writing `~/.config/tier0/with_lane_env.sh` and plaintext `.env.{data,paper}` placeholders reinvented a brittle subset of `fnox` while causing Windows/WSL2 credential drift and security risk.
- **Mechanical Upstream Gates:** `tests/test_grand_reset_kit.py` asserts `fnox.toml` schema + zero `AGE-SECRET-KEY-` / plaintext `PK...`/`AK...` tokens, `fnox`/`age` pins in `mise.toml`, `ADR-0023.md` in `docs/adr/` and `zensical.toml`, and removal of `with_lane_env.sh` generation from `01_wsl_bootstrap.sh`; `gitleaks`, `trivy`, `shellcheck`, and `zensical build --clean --strict` enforce ongoing hygiene.

### Compounding Layer Integration

- Feeds live `just scan` (`live_whole_market_movers_manifest.json`) and 4-account `just paper-farm` telemetry seamlessly into `Z:\sota-data\manifests`, `DuckDB`, `FINOS`/`OpenBB`, `MLflow`, and `XERJ` across all four compounding harness lanes (`sim-backtest`, `paper`, `half-auto-tv`, `live`) on both Windows and WSL2 without manual credential exports.
