# ADR-0005: Formal Immutable Risk Kernel & Z3 SMT Proofs (`risk.py` Rule-612 `<= 2.00%`, `-1.50%` Fuse, `>= 10%` Reserve)

- **Status:** Accepted
- **Date:** 2026-11-26
- **Evidence Grade:** E4
- **Sole Source of Truth:** SOTA upstream convergence per Core Trading Philosophy

## Context and Problem Statement

Floating-point rounding drift, unquantized sub-dollar ticks, unchecked intraday drawdowns, or broker API rate exhaustion can breach maximum per-trade loss bounds or block protective exits during volatility spikes. Example-based unit tests alone cannot prove universal invariants over all positive prices.

## Decision Drivers

- Exact `Decimal` and integer-tick arithmetic (`float()` forbidden) complying with Reg-NMS Rule-612 (`$0.01 >= $1.00`, `$0.0001 < $1.00`).
- Conservative inward stop quantization guaranteeing initial stop distance never exceeds `2.00%` (`MAX_STOP_LOSS_PCT`).
- Session-latched `-1.50%` daily drawdown circuit breaker and `>= 10%` protective exit API rate reserve.
- Universal machine-checked SMT counterexample refutation via `z3-solver` (`UNSAT`) and property fuzzing via `Hypothesis`.

## Considered Options

1. **Inline float stop calculations guarded only by example tests** — vulnerable to sub-dollar rounding beyond `2.00%` and untested edge cases.
2. **SHA-256-immutable `src/tier0_sota/risk.py`** formally verified by `evals/formal_risk_z3.py` (`z3-solver` `UNSAT`), `Hypothesis` property fuzzing, and `ast-grep`.

## Decision Outcome

Adopt Option 2 in conjunction with [ADR-0016](ADR-0016.md). `src/tier0_sota/risk.py` remains byte-identical (`361` lines, SHA-256 `ad8071dcd4196c4c529c02107114ebfdda6692bc9d7c220031f1b19ea3e4d847`, excluded from `ruff format`, protected in `.github/CODEOWNERS`). Every execution, Paper Farm, and TradingView module delegates `quantize_rule_612`, `compute_capped_stop_price`, `size_position_by_risk`, `DailyDrawdownBreaker`, and `ProtectiveExitRateBudget` to `risk.py`.

## Consequences

- **Positive:** Proves Rule-612 stop bounds (`<= 2.00%`), latched `-1.50%` drawdown fuse, and `>= 10%` exit reserve universally via `Z3` `UNSAT` and cryptographic SHA-256 immutability on `src/tier0_sota/risk.py`.
- **Negative:** Prevents any automated formatting or parameter tweaking of `risk.py`; any kernel change requires a formal proof update, SHA-256 re-pinning, and `CODEOWNERS` review.

### Self-Invention Lesson Learned & Mechanical Upstream Gate

- **Lesson Learned:** Tracking arbitrary line-count caps on `risk.py` or formatting it with automated formatters risked silent hash drift without adding mathematical safety. Immutability is enforced strictly by cryptographic SHA-256 + formal SMT proof, never LOC caps.
