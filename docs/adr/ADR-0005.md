# ADR-0005: Formal Immutable Risk Kernel & Z3 SMT Proofs (`risk.py` Rule-612 `<= 2.00%`, `-1.50%` Fuse, `>= 10%` Reserve)

- **Status:** Accepted
- **Date:** 2026-11-25
- **Evidence Grade:** E4

## Context and Problem Statement

Floating-point rounding drift, unquantized sub-dollar ticks, unchecked intraday losses, or API rate exhaustion can breach maximum per-trade risk or prevent protective exits during market stress. Unit tests alone cannot prove universal boundary properties across all positive prices.

## Decision Drivers

- Exact `Decimal` arithmetic (`float()` forbidden) with Reg-NMS Rule-612 ticks (`$0.01 >= $1.00`, `$0.0001 < $1.00`).
- Conservative inward stop quantization so stop loss never exceeds `2.00%` (`MAX_STOP_LOSS_PCT`).
- Session-latched `-1.50%` daily drawdown circuit breaker and `>= 10%` protective exit API rate reserve.
- Universal machine-checked formal SMT proofs (`z3-solver`) verifying zero counterexamples (`UNSAT`).

## Considered Options

1. **Inline float stop calculations with example-based unit tests** — prone to rounding beyond `2.00%` and untested edge ticks.
2. **Standalone, SHA-256-immutable `src/tier0_sota/risk.py` (`361` LOC)** formally proven via `evals/formal_risk_z3.py` (`z3-solver` `UNSAT`), `Hypothesis`, and AST guards.

## Decision Outcome

Adopt Option 2. `src/tier0_sota/risk.py` is preserved verbatim (SHA-256 `ad8071dcd4196c4c529c02107114ebfdda6692bc9d7c220031f1b19ea3e4d847`, `361` LOC). All strategy, paper-farm, and TradingView modules delegate Rule-612 quantization (`quantize_rule_612`), capped stops (`compute_capped_stop_price`), risk sizing (`size_position_by_risk`), drawdown latching (`DailyDrawdownBreaker`), and exit rate budgets (`ProtectiveExitRateBudget`) directly to `risk.py`. `evals/formal_risk_z3.py` models the integer-tick Rule-612 stop cap, `>= 10%` exit reserve, and `-1.50%` latched drawdown fuse in `z3` and proves every violation query returns `UNSAT` (`Z3_FORMAL_RISK_PROOFS_UNSAT_OK=1`).

### Consequences

- **Positive:** Mathematically proven `<= 2.00%` stop cap, `>= 10%` exit reserve, and `-1.50%` fuse across sub-dollar and dollar regimes.
- **Negative:** Any modification to `risk.py` fails the repository SHA-256 verification gate unless explicitly re-ratified and re-proven.
