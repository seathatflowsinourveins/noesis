# ADR-0003: Causal Point-in-Time Data Plane (`<= 2026-10-15`, `t_ns + 60s`, `XNYS`)

- **Status:** Accepted
- **Date:** 2026-11-25
- **Evidence Grade:** E4

## Context and Problem Statement

Backtests and signal pipelines fail silently when future data leaks via restatements, unshifted bar timestamps, missing exchange-calendar half-days, or post-cutoff observations.

## Decision Drivers

- Strict pre-wall temporal boundary (`<= 2026-10-15` UTC) for historical research.
- Exact causal bar-availability lag (`ts_available_ns >= t_ns + 60_000_000_000`) and SEC `accepted_ns <= as_of_ns` / FINRA `T-1` publication alignment.
- Official `XNYS` calendar classification including `13:00 ET` early-close sessions.

## Considered Options

1. **Naive pandas resampling with weekday-only checks** — leaks holidays, half-days, and bar-open lookahead.
2. **Causal `Polars` + `DuckDB` + `Pandera` + `exchange_calendars` (`XNYS`) + `EdgarTools` PIT plane**.

## Decision Outcome

Adopt Option 2 in `src/tier0_sota/discovery.py` and `src/tier0_sota/engine.py`. All historical pre-wall joins filter strictly `ts_ns <= PREWALL_CUTOFF_NS` (`2026-10-15`), enforce `as_of_ns >= event_ns + 60s` on 1-minute bars, validate schemas with `Pandera`, and resolve US equity sessions (`PRE_MARKET`, `RTH`, `AFTER_HOURS`, `OVERNIGHT`, `CLOSED`) via `exchange_calendars` (`XNYS`).

### Consequences

- **Positive:** Eliminates forward-looking bias across bars, SEC filings (`EdgarTools`), and macro releases (`FRED`).
- **Negative:** Signals referencing unverified or post-wall timestamps fail closed.
