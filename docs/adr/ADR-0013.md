# ADR-0013: Multi-Tier Market, Microstructure, Borrow & Fundamental Data Feeds Convergence

- **Status:** Accepted
- **Date:** 2026-11-26
- **Evidence Grade:** E4
- **Sole Source of Truth:** SOTA upstream convergence per Core Trading Philosophy
- **Related:** [ADR-0003](ADR-0003.md) (Causal PIT Data Plane), [ADR-0004](ADR-0004.md) (Single-Engine Parity), [ADR-0007](ADR-0007.md) (24/5 Session Protection), [ADR-0008](ADR-0008.md) (Extreme Movers & Market-Aligned Shorting), [ADR-0009](ADR-0009.md) (Paper Farm)

## Context and Problem Statement

The Core Trading Philosophy needs four kinds of data, each with its own latency, licensing and point-in-time (PIT) needs:

1. **Market tape (L1/bars):** finding extreme movers across the whole market and classifying the causal regime (`SPY`, `QQQ`, `SOXX`, `RSP`, `VIX`).
2. **Microstructure (L2 `MBP-10` / L3 `MBO`):** queue-position markout and fill realism for `hftbacktest` and `NautilusTrader v2` parity (ADR-0004, ADR-0006).
3. **Borrow / short-sale state:** ETB/HTB routing (`DIRECT_SHORT_ETB` vs `INVERSE_HEDGE_SOXS_SQQQ`), Reg SHO short volume, FINRA short interest.
4. **Fundamentals & macro:** SEC 8-K/10-Q/Form-4 events with `accepted_ns <= as_of_ns`, share count and float, and ALFRED/FRED vintages.

The market structure changes on **2026-12-06**. From Sunday 21:00 ET, the CTA/UTP SIPs run **23x5** (Sun 21:00 ET to Fri 20:00 ET, with a daily 20:00 to 21:00 ET maintenance pause). Broker overnight venues (Blue Ocean ATS via Alpaca `DataFeed.BOATS` / `DataFeed.OVERNIGHT`, and the IBKR `OVERNIGHT` route) start at 20:00 ET. Without one tiered feed policy, the data plane risks four problems:

- unvalidated vendor scrapers;
- mixing feeds with different timestamp semantics;
- leaking post-wall data into pre-wall research;
- adopting data infrastructure that is not OSI-licensed.

## Decision Drivers

- **Upstream-only feeds:** every feed must come from an official SDK or adapter that is pinned in `uv.lock`, or from a public regulator dataset (SEC EDGAR, FINRA, ALFRED/FRED). Unofficial scrapers are banned. `upstream-map.toml` already bans `yfinance` and `pandas-datareader`.
- **One PIT contract across all tiers:** pre-wall cutoff `<= 2026-10-15` (`DISCOVERY_WALL_UTC_NS`, `PreWallViolationError`), bar availability `t_close_ns = t_ns + 60s`, SEC `accepted_ns <= as_of_ns`, FINRA T-1 / publication-date alignment, ALFRED `vintage_date <= as_of`.
- **24/5 → 23x5 continuity:** session labels must match the SIP 23x5 timetable and the broker overnight (BOATS) timetable after 2026-12-06. `OVERNIGHT` shorts stay blocked (`paper_farm.submit_guarded_entry` refuses `SHORT` + `OVERNIGHT`). ETB routing is skipped in `OVERNIGHT` (`select_short_or_inverse_fallback`).
- **Borrow truth before shorting:** check `shortable`, `easy_to_borrow` and `borrow_status` after selection, using the official `alpaca-py` asset API (`live/scanner.py`). IBKR paper (`:4002`) can supply a second opinion through generic tick `236` (shortable indicator).
- **SPDX OSI license firewall:** client libraries and storage formats must use OSI-approved licenses (MIT / Apache-2.0 / BSD / LGPL). Data vendors' commercial redistribution terms are a separate question, recorded as data-licensing, never as code dependencies.
- **Safety invariants unchanged:** `paper_only=True`, `live_execution_enabled=False`, `src/tier0_sota/risk.py` is immutable (SHA-256 `ad8071dc…e4d847`), and live broker ports `4001/7496/8798/8796` stay fail-closed.

## Considered Options

1. **Single retail feed (IEX-only bars) plus web scraping for borrow and fundamentals.** Cheap, but IEX covers only a small share of consolidated volume. Scraped borrow and filings data has no PIT provenance and violates the banned-library gate. Rejected.
2. **One commercial vendor for everything (for example, an all-in-one L3 + fundamentals + borrow vendor).** This concentrates vendor lock-in. Fundamentals and borrow from a single vendor are not regulator-sourced PIT, and the parity engine's native adapters would be duplicated. Rejected.
3. **Multi-tier convergence on official upstream SDKs and regulator datasets, with earned-trigger promotion for L2/L3 and for L11 lake tooling (chosen):**
   - **Tier A, market tape (active):** `alpaca-py==0.45.0`, `DataFeed.SIP` (whole-market scan + FINRA TRF `Exchange.D` darkpool share), with `DataFeed.BOATS` / `DataFeed.OVERNIGHT` for 20:00 to 04:00 ET indicative overnight quotes. Historical 1-minute SIP bars are kept in the pre-wall lake.
   - **Tier B, microstructure (earned trigger):** Databento `MBP-10` (→ `OrderBookDepth10`) and `MBO` (→ `OrderBookDelta`), consumed only through the **native NautilusTrader Databento adapter** (`DatabentoDataLoader` for DBN → Parquet catalog under `Z:\sota-data\nautilus-catalog`) and the `databento-python` client (Apache-2.0). It is promoted only when an `hftbacktest` queue-markout gate needs L2/L3 depth that SIP L1 cannot provide. `uv.lock` has **0** `databento` entries today.
   - **Tier C, borrow / short-sale (active):** the Alpaca asset API (`shortable`, `easy_to_borrow`, `borrow_status`, `overnight_tradable`), FINRA Reg SHO daily short-sale volume and FINRA Rule 4560 twice-monthly short interest (published on the 7th business day after settlement; joined on publication date, never on settlement date). IBKR paper generic tick `236` is a second opinion only, through the paper gateway `:4002`.
   - **Tier D, fundamentals & macro (active):** `edgartools==6.4.0` (MIT) for 8-K / 10-Q / 10-K / Form-4 / XBRL, keyed on EDGAR `accepted` timestamps, and `fredapi==0.5.2` (Apache-2.0) with ALFRED vintages.
   - **Bulk-history alternative (watch):** Massive (formerly Polygon.io) S3 flat files. These are daily gzip CSV trades and quotes on an S3-compatible endpoint with separate S3 credentials, available around 11:00 ET on the next day. This is a commercial data-licensing decision. It is admitted only through an earned trigger plus a verified OSI client, never as a code-level vendor shim.
   - **Data plane (active, ADR-0003):** `polars==2.2.0`, `duckdb==2.0.1`, `pandera==0.36.0`, `pydantic==2.14.4`, `exchange-calendars==4.13.3` (`XNYS`), `pyarrow==26.0.1`, `dvc==3.67.1`.

## Decision Outcome

Adopt **Option 3**. Every feed enters through the existing upstream adapters, with no new wrappers:

- `src/tier0_sota/live/scanner.py`: `alpaca-py` `DataFeed.SIP`, FINRA TRF `Exchange.D` share, and ETB lookup after selection.
- `src/tier0_sota/live/paper_farm.py`: `paper_only=True` lanes, `OVERNIGHT` short refusal, and inverse-hedge fallback.
- `src/tier0_sota/discovery.py`: Pandera-validated causal bars, `PreWallViolationError`, `XNYS` sessions, and Nautilus `BarDataWrangler`.
- **Tier B** is admitted only through `nautilus_trader.adapters.databento` (no custom DBN parser).

**L11 lake candidates** (`SOTA_STARRED_AND_BEYOND_MANIFEST.json` → `earned_trigger_frontier_l11_to_l15.L11`) stay **watch-only** until their triggers fire:

| Candidate | SPDX | Earned trigger | Current measurement |
|---|---|---|---|
| `vortex-data/vortex` (LF AI & Data, incubation) | Apache-2.0 | lake > 100 GB/run | pre-wall lake ≈ 29.1 GiB total. **Not fired.** |
| `lancedb/lancedb` | Apache-2.0 | multimodal SEC filings | `sec_filings.parquet` is tabular metadata only. **Not fired.** |
| `tobymao/sqlglot` | MIT | PIT SQL static transpilation | DuckDB SQL is generated by Polars/DuckDB natively. **Not fired.** |
| `dlt-hub/dlt` | Apache-2.0 (core library) | declarative PIT ingest pipelines | ingest is receipt-driven (`prewall-lake/receipts/`). **Not fired.** |

Hosted/managed tiers of these projects are out of scope. Only the OSI-licensed core libraries are eligible.

### Self-Invention Lesson Learned & Mechanical Upstream Gate

- **Lesson learned:** past plans to hand-roll Databento DBN decoders, add REST polling loops for borrow status, or scrape short-interest pages would have duplicated adapters that `nautilus_trader`, `alpaca-py` and FINRA/SEC public files already provide. They would also have hidden timestamp semantics (settlement date vs publication date for short interest, filing date vs `accepted` for SEC). Every tier now carries its upstream's native timestamp, and PIT alignment happens in exactly one place (`discovery.py`, ADR-0003).
- **Mechanical gates:**
  - `upstream-map.toml` `banned_libraries` / `banned_packages` (`yfinance`, `pandas-datareader`, …) plus `rejected_overlaps` for L4 (`custom-rest-polling-loops`, `raw-unfiltered-alpaca-mcp-server`).
  - `rules/zero_self_invention.yml` (ast-grep).
  - `deptry`, the `uv.lock` single-winner check and the SPDX OSI firewall.
  - `PreWallViolationError` plus the Pandera `t_ns <= DISCOVERY_WALL_UTC_NS` check.
  - `paper_farm` `PermissionError` on any non-paper mode or attempt to enable live execution.
  - `forbidden_live_hosts = ["api.alpaca.markets"]` and `forbidden_live_ports`.
  - `just check` / `prek run --all-files` / `pytest`.

### Compounding Layer Integration

- **`sim-backtest`:** pre-wall SIP 1-minute bars plus SEC, FINRA and ALFRED tables feed `MLflow` trials and the Dagster asset `prewall_pit_audit`. Tier B depth, once promoted, lands in `Z:\sota-data\nautilus-catalog` for `hftbacktest` queue markout (ADR-0006 gate 1).
- **`paper`:** Tier A SIP/BOATS feeds plus Tier C borrow checks drive the 4-account Paper Farm (ADR-0009). Results compound into per-lane DuckDB ledgers and `Z:\sota-data\manifests`.
- **`half-auto-tv`:** the same Tier A extreme-mover selection and Tier C ETB routing produce `TvAlertV1` tickets (ADR-0010).
- **`live`:** consumes identical feed contracts but stays at `live_execution_enabled=False` / `paper_only=True` until a separately governed Stage-5 ADR.

### Living Evolution & Supersession Policy

- This ADR is a living empirical snapshot, not frozen dogma. Amend it, or mark it `Superseded by ADR-XXXX`, when any of these happens:
  - an L11 trigger fires (lake > 100 GB/run, multimodal filings, PIT SQL transpilation, declarative ingest);
  - Tier B L2/L3 depth is promoted after a measured `hftbacktest` markout gain;
  - the 2026-12-06 SIP 23x5 cutover changes vendor feed enums or session timetables;
  - a superior OSI-licensed upstream better realizes the Core Trading Philosophy.
- Every amendment must re-verify `uv.lock` pins, SPDX licenses and pre-wall lake receipts. It must also preserve `risk.py`, `paper_only=True` and live-port isolation.
