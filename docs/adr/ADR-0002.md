# ADR-0002: Four Dedicated Compounding Harness Lanes & Dual-Flywheel Learning (`sim-backtest`, `paper`, `half-auto-tv`, `live`)

- **Status:** Accepted
- **Date:** 2026-11-26
- **Evidence Grade:** E4

## Context and Problem Statement

Quantitative engineering stalls when backtesting, paper trading, TradingView staging, and Stage-5 live readiness operate as isolated one-off scripts or passive status summaries instead of active compounding lanes connected to durable experiment ledgers, memory indices, and offline safety evaluations.

## Decision Drivers

- Operate 4 dedicated compounding harness lanes (`sim-backtest`, `paper`, `half-auto-tv`, `live`) anchored on one AAIF `AGENTS.md` SSOT (`CLAUDE.md` -> `@AGENTS.md`) and declarative `mise`/`just`/`prek`.
- Persist every pre-wall trial (`<= 2026-10-15`), paper fill/markout receipt, and TradingView alert cycle into deterministic compounding manifests (`MLflow`, `DuckDB`, `Z:\sota-data\manifests`, `XERJ`).
- Separate synchronous trading execution hot paths from asynchronous LLM/RAG/eval tooling (`Inspect AI`, `DSPy`, `XERJ`).

## Considered Options

1. **Passive read-only lane reports and ad-hoc markdown notes** — fails to close the empirical feedback loop between Sim, Paper, TV, and Live readiness.
2. **4 Active Compounding Harness Lanes + Cross-Cutting Compounding Layer (`MLflow` + `DuckDB` + `Z:\sota-data\manifests` + `XERJ` + `Inspect AI`/`DSPy` + `sync_manifest.py`)**.

## Decision Outcome

Adopt Option 2:
1. **`sim-backtest`:** 24/7 `NautilusTrader v2` `BacktestEngine`/`Environment.SANDBOX` + Rust `hftbacktest`, strict causal PIT (`<= 2026-10-15`), upstream feature/regime/ML discovery + `Optuna`, independent long/short 6-gate falsification -> compounding `MLflow` manifests.
2. **`paper`:** Stationary Noesis 4-account Paper Farm (`IBKR :4002` + 3 non-overlapping `Alpaca Paper 200 rpm` lanes), real-time extreme-mover scanning & ETB/inverse routing, 24/5 trailing/auto-reverse/re-entry, isolated `DuckDB` + `MLflow` fill/markout manifests, and live `FINOS`/`OpenBB`/`Grafana`/`OTel` telemetry.
3. **`half-auto-tv`:** TradingView Pine v6 cockpit, strict Pydantic v2 (`TvAlertV1`) bridge & staged semi-auto tickets (`semi_auto_confirmed = False`), closing telemetry back into Sim/Paper compounding manifests.
4. **`live`:** Stage-5 promotion-readiness & `Sim == Paper == Live` `NautilusTrader v2` `LiveNode`/`InteractiveBrokers` parity lane, `Z3` SMT proofs, `Inspect AI` safety suite, and cross-leg 6-gate promotion dossiers (`live_execution_enabled = False` until full promotion).

### Upstream Evidence & Official Directives

- **AAIF `AGENTS.md` Standard & Multi-Runtime Discovery:** Canonical `AGENTS.md` with `@AGENTS.md` (`CLAUDE.md`), `.gemini/settings.json` native `context.fileName`, `stablyai/orca` (`orca.yaml`), and `modelcontextprotocol/python-sdk` (`FastMCP`).
- **Compounding Infrastructure:** `mlflow/mlflow` (`:5000`), `duckdb/duckdb` (`Z:\sota-data\manifests`), `xerj-org/xerj` (`:9200`), `UKGovernmentBEIS/inspect_ai` (`evals/tier0_inspect_eval.py`), `stanfordnlp/dspy`, `jdx/mise`, `casey/just`, `j178/prek`.

### Self-Invention Lesson Learned & Mechanical Upstream Gate

- **Lesson Learned:** Custom shell hook wrappers (`rtk`, custom `harness_directive_hook.py`, `.codex/hooks.json`), duplicated per-runtime instruction prose, and arbitrary command/agent line caps added brittle indirection without improving safety or strategy merit. All were purged.
- **Mechanical Upstream Gates:** `tests/test_architecture_manifest.py` (`zero_self_invented_hooks`, `CLAUDE.md == "@AGENTS.md"`, 5/5 native `uv` MCP parity), `evals/tier0_inspect_eval.py`, `rules/zero_self_invention.yml` (`no-llm-on-execution-hot-path`), and `just check`.

### Compounding Layer Integration

- Defines the cross-cutting Compounding Layer itself: `sim-backtest` writes pre-wall 6-gate `MLflow` runs, `paper` and `half-auto-tv` emit `DuckDB` + JSON manifests under `Z:\sota-data\manifests`, `XERJ` deduplicates verified lessons, and `live` aggregates cross-lane readiness dossiers verified E2E via `pytest` and `Inspect AI`.
